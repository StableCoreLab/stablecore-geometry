# 审查与整改归档

本目录集中保存代码审查产生的记录、整改方案及 D1--D6 的设计/实施基线；它们描述审查过程和阶段结论，不作为产品使用说明。

| 文档 | 用途 |
| --- | --- |
| `审查记录.md` | 原始问题、风险与审查结论 |
| `审查问题修复方案.md` | 整改状态、验收要求与提交线索 |
| `design-proposals-d1-d6.md` | D1--D6 的设计边界和实施门槛 |
| `d1-dependency-report.md` 至 `d6-ring-traversal-audit.md` | 各设计项的实施报告、基线或审计结论 |

持续维护的产品设计、能力矩阵、使用说明和同步跟踪仍位于 `docs/` 根目录。
