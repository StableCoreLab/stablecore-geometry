# D4：分阶段通用凸多面体布尔内核

## 状态与目标

状态：D4-0、`BooleanSolid3d`、独立 oracle 与“不含重合支撑平面的凸多面体正体积相交”已实施；本文仍不承诺一般 CSG。

现有 `BodyBoolean` API 有意只支持确定性的盒体子集。下一项能力不是“通用 CSG”，而是两个有效、单壳、平面、凸多面体（包括旋转盒）的相交。该子集的并集和差集在具备片段分类与壳重建能力前继续保持不支持。

这一边界仅引入一个可验证的几何操作——半空间裁剪——而不会对任意 B-rep 编辑作出不具备实现基础的承诺。

## 输入与结果契约

`BodyBoolean` 的所有当前已支持子集（包括可确认几何等价/相离和轴对齐盒快速路径）均先要求边为端点一致的直线 `SCLineCurve3d`；不得把曲线边的端点弦段当作边界。“几何等价”同时比较 face 支撑面与边界环，不能用拓扑计数或包围盒替代。首个通用凸体相交内核还要求两个 body 同时满足下列条件：

1. 恰有一个有效且闭合的 shell；平面 face 的 outer/hole loop 顶点必须在支撑平面的距离容差内；
2. 面为平面面片，顶点坐标有限，边界由端点一致的直线 `SCLineCurve3d` 组成且不含零长度边；
3. 实体具有一致的向外朝向并且为凸体；
4. 两个操作数之间不存在重合支撑平面。

相离输入继续使用既有的确定性空相交结果。超出上述契约的有效输入返回 `UnsupportedOperation`，并保证 `body` 为空、`bodies` 为空、`producedEmptyResult == false`。一旦验证层能够区分，非法或开口输入继续返回 `InvalidInput`，而不与“有效但尚不支持”的形体混淆。

成功结果必须是恰有一个闭合 shell 的有效 body。其顶点在给定距离容差内满足全部保留半空间；交换操作数不得改变体积和包围盒。面或边的存储顺序不是公开不变量。

`operateOnShells` 与 `preserveInputOrientation` 当前尚未具备可验证的策略语义。新内核不得把它们视为已生效；在支持多壳输入或调用方朝向保持前，必须先通过后续 API 修订明确其含义。

## 内部模型

计算过程中保持公开 `SCBrepBody` 不可变。在 B-rep 实现边界下新增仅内部使用、按值持有的类型：

| 内部值类型 | 职责 |
| --- | --- |
| `BooleanSolid3d` | 规范化后的 shell、向外面平面、容差与来源标识 |
| `BooleanVertex3d` | 点坐标及来源（`first`、`second` 或面面交） |
| `BooleanFaceFragment3d` | 拓扑构造前的一个支撑平面和定向多边形片段 |
| `BooleanIntersectionGraph3d` | 面对交线段与端点关联，供后续非凸阶段使用 |
| `BooleanClassification3d` | 内部、外部、边界及显式歧义状态的分类 |
| `BooleanShellCandidate3d` | 转换为 `SCBrepBody` 前待验证的、按值持有的片段集合 |

内部类型不得暴露对输入 body 的引用。每个阶段要么返回完整的值对象，要么返回失败分类；不得修改输入，也不得发布部分组装的 shell。

## 处理流水线

1. **验证与规范化。** 检查 shell 闭合性、有限坐标、面环、朝向和凸性，构造 `BooleanSolid3d`；不满足首期子集的输入直接拒绝。
2. **粗筛。** 用包围盒快速返回相离结果，并为后续阶段枚举可能相交的面对。
3. **几何相交。** 在凸体相交阶段，用另一实体的每个定向面半空间裁剪一个凸体；保留新顶点来源，并区分空、低维和正体积结果。
4. **片段构造。** 将保留的凸单元转换为朝向一致的平面面片；按拓扑容差移除零面积片段。
5. **拓扑组装。** 仅在当前候选中去重顶点与边，构造 shell，并验证边关联数、环闭合、朝向、shell 闭合和体积符号。
6. **提交。** 仅当全部校验通过后，才将完整候选转换为 `SCBrepBody`。任何歧义或验证失败均返回非成功结果并丢弃候选。

并集和差集会复用第 1 至第 4 阶段，再增加片段分类、共面归属策略、重合消解和多 shell 组装；它们不与“凸体相交”里程碑绑定交付。

## 容差与退化策略

- 默认 `BodyBooleanOptions3d` 使用当前 Boolean 默认距离容差；显式 `distanceEpsilon == 0.0` 表示严格距离比较。平行/共面角度比较使用单位法向量叉积长度与 `angleEpsilon`，保持与 3D 关系谓词一致；显式 `angleEpsilon == 0.0` 表示严格角度比较。任一容差为负数或非有限值时返回 `InvalidInput`。
- 点落在裁剪平面容差带内时标记为 `on-boundary`，不得任意归类到内部或外部。
- 零体积相交、相切接触、共边、共点和共面重叠必须在构造 shell 前分类。既有盒体的空/多 body 行为不变；一般非盒体的歧义情况继续返回不支持。曲线边界不以端点弦段替代，统一返回不支持。
- 顶点合并和零面积面删除使用从输入距离容差显式推导出的拓扑容差，禁止悄然改用无关的全局 epsilon。
