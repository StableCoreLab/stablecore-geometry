# StableCore Geometry 使用说明

- 适用版本：当前 `main` 分支（HEAD e25b0d2）
- 更新日期：2026-09-01
- 环境要求：CMake ≥ 3.16、C++20；默认面向 Visual Studio 2022 x64（Windows），CMake 亦可生成其他生成器

本文档是面向**使用者**的完整说明：构建、安装、集成、模块能力、代码示例与已知限制。结构性设计说明见 [library-design.md](library-design.md)，当前结构性问题见 [审查记录.md](审查记录.md)。

---

## 1. 简介

StableCore Geometry（工程标识 `SCGeometry`）是一套面向工程计算的 C++ 几何库，目标是把稳定、可测试、可发布的几何能力以统一的公开 API 提供给产品侧。当前发布面包括：

- 二维：值类型、图元（线段/圆弧/圆/椭圆/矩形）、折线/多边形/复合路径、相交/投影/距离/关系/布尔/偏移/搜索服务
- 三维：值类型与线性代数、曲线（直线/NURBS/曲面上曲线）、曲面（平面/NURBS/规则/偏移）、空间搜索、网格（`TriangleMesh`）
- BRep：拓扑（Body/Shell/Face/Loop/Coedge/Edge/Vertex）、Polyhedron 平行实体、布尔、转换、修复（Healing）、网格转换与网格修复、平面截切（Section）
- 其他：文本序列化（`Geometry::Serialize`）、容差常量（`Support/Epsilon.h`）

所有公共符号位于命名空间 `Geometry`。

## 2. 构建

### 2.1 前置

- CMake ≥ 3.16
- Visual Studio 2022（含 C++ 工作负载）或任何受支持的 CMake 生成器
- 测试依赖 GoogleTest：优先 `find_package(GTest)`，否则使用仓库旁 `../ThirdParty/GoogleTest` 的本地副本，都不存在时回退从 GitHub 下载 `googletest v1.17.0`（断网环境需提前准备本地副本）

### 2.2 方式一：批处理脚本（VS2022 默认路径）

```bat
GenerateGeometryVS2022.bat
```

在仓库根目录外生成 `../Build/GeometryVs2022` 的 VS 解决方案。可传 4 个可选参数：`build_dir generator arch build_tests`。

### 2.3 方式二：CMake preset（推荐）

```bat
cmake --preset vs2022-x64                 REM 配置
cmake --build --preset vs2022-x64-build --config RelWithDebInfo
ctest --preset vs2022-x64-test -C RelWithDebInfo
```

预设还提供 `vs2022-x64-fast`（开启 PCH）用于加速本地迭代。`.vscode/settings.json` 已配置 VS Code CMake Tools 复用同一套 preset。

### 2.4 CMake 选项

| 选项 | 默认 | 说明 |
|------|------|------|
| `SCGEOMETRY_BUILD_TESTS` | `ON` | 构建测试（`SCGeometryCapabilitiesTests` / `SCGeometryGapTests` 两个 exe） |
| `SCGEOMETRY_ENABLE_PCH` | `OFF` | 启用预编译头（加速选项） |
| `SCGEOMETRY_ENABLE_UNITY_BUILD` | `OFF` | 启用 Unity Build（加速选项），批次大小 `SCGEOMETRY_UNITY_BUILD_BATCH_SIZE`（默认 8） |

### 2.5 产物

构建产物输出到仓库外的 `../Bin/<Config>/<Platform>`（默认 `<Platform>` 为 x64）：

- `SCGeometry.dll`（+ PDB，RelWithDebInfo/Release 带 `/DEBUG`）
- `SCGeometry.lib`（导入库）
- 测试可执行文件

> 当前工程固定 `add_library(... SHARED ...)`，无静态库选项。

## 3. 安装

```bat
cmake --install ../Build/GeometryVs2022 --config RelWithDebInfo --prefix <你的前缀>
```

默认前缀为 `C:/Program Files/SCGeometry`。安装布局：

```text
<prefix>/
├── Include/SCGeometry/          # 公开头文件（按 Core/Geometry2d/... 分层）
├── Lib/<arch>/<config>/         # 导入库
├── Lib/cmake/SCGeometry/        # CMake 包文件（SCGeometryConfig.cmake 等）
└── Bin/<arch>/<config>/         # DLL（+ PDB）
```

安装面刻意收口：实现细节头（`Types/Detail`、`Types/Compat`）不进入默认安装。

## 4. 集成到下游项目

### 4.1 安装包方式

```cmake
find_package(SCGeometry CONFIG REQUIRED)
target_link_libraries(your_target PRIVATE SCGeometry::Geometry)
```

### 4.2 源码方式（add_subdirectory / FetchContent）

```cmake
add_subdirectory(third_party/SCGeometry)
target_link_libraries(your_target PRIVATE SCGeometry::Geometry)
```

### 4.3 包含头文件

统一入口（推荐）：

```cpp
#include "Geometry.h"
```

按模块按需包含（例如只用到 2D 相交时）：

```cpp
#include "Core/Intersection.h"
#include "Geometry2d/SCLineSegment2d.h"
```

### 4.4 重要：DLL 消费者的导出宏

当前库把 `GEOMETRY_BUILD_DLL` 设为 `PRIVATE`，但**尚未**向下游传播 `GEOMETRY_USE_DLL`。如果你通过 `find_package` 消费且使用 MSVC，请在目标上显式补上：

```cmake
target_compile_definitions(your_target PRIVATE GEOMETRY_USE_DLL)
```

否则 `GEOMETRY_API` 在消费者侧为空，读取导出的数据常量（`Geometry::kPi`、各 epsilon 等）会得到错误值。此问题已记录在 [审查记录.md](审查记录.md) H2，库侧修复后会不再需要手动定义。

## 5. 目录分层与公共入口

```text
Include/
├── Core/          # 结果类型 + 跨模块算法门面（相交/投影/关系/度量/布尔/偏移/变换/验证/搜索/截面）
├── Geometry2d/    # 2D 图元与路径工具（线段/圆弧/圆/椭圆/矩形/折线/多边形/路径操作/搜索索引）
├── Geometry3d/    # 曲线/曲面接口与实现、曲面上曲线、网格、3D 搜索
├── Brep/          # BRep 拓扑、Polyhedron、Mesh、布尔、转换、修复、Tessellation、Topology
├── Types/         # 值类型（Geometry2d / Geometry3d 子目录），header-only
├── Support/       # 容差常量（Epsilon.h）、2D 谓词/归一化辅助
├── Serialize/     # 文本序列化
└── Export/        # GEOMETRY_API 导入导出宏
```

依赖方向（设计意图）：`Types`/`Support` 为底层，向上经 `Geometry2d`/`Geometry3d`、`Brep` 到 `Core`。**注意**：当前实现中 `Core` 若干算法头直接 include `Brep`/`Geometry2d`，分层有回环，属于已知结构问题（见审查记录 H1），不影响 API 使用。

## 6. 核心概念

### 6.1 容差

- 默认容差 `Geometry::kDefaultEpsilon = 1e-9`
- 数值谓词：`IsZero` / `IsEqual` / `AbsValue`（`Support/Geometry2d/Predicate2.h`，同时提供 2D 向量的 `Dot`/`Cross`）
- 2D 算法通常收 `double eps = kDefaultEpsilon` 参数；3D 算法通常收 `const SCGeometryTolerance3d& tolerance = {}`（含 `distanceEpsilon`/`angleEpsilon`/`parameterEpsilon`/`boxPadding` 四元组）
- 规范化：`SCVector2::Normalized(eps)`（退化返回零向量）；`TryNormalize(vector, out)`（bool + 出参报告失败）

### 6.2 结果类型模式

几何服务通常不返回裸 `bool`，而是返回**结构化结果**，带 `IsValid()`/`AlmostEquals()`/`DebugString()`，便于诊断：

```cpp
const auto hit = Intersect(lineSegA, lineSegB);
if (hit.HasIntersection()) { /* hit.points, hit.pointCount, hit.kind */ }
```

3D 服务结果常带 `success` 标志与 `issue` 枚举（如 `SCSectionIssue3d`），约定：`success == false` 时结果视为无效。

### 6.3 接口风格

- PascalCase 短名：`Count()`、`Bounds()`、`Length()`、`PointAt()`、`IsValid()`
- 多对象/需要容差/复杂度高的操作走自由函数（`Intersect`、`Offset`、`ProjectPointToSegment`）
- 对象自身天然属性走成员函数（`Length()`、`Area()`、`StartPoint()`）

## 7. 二维能力

### 7.1 值类型（`Types/Geometry2d`，header-only）

```cpp
#include "Types/Geometry2d/SCPoint2.h"
#include "Types/Geometry2d/SCVector2.h"
#include "Types/Geometry2d/SCBox2.h"
#include "Types/Geometry2d/SCMatrix2d.h"
#include "Types/Geometry2d/SCTransform2d.h"

using Geometry::SCPoint2d;
using Geometry::SCVector2d;

const SCPoint2d p(1.0, 2.0);
const SCVector2d v(3.0, 4.0);
const SCPoint2d q = p + v;          // 点 + 向量
const double d = (q - p).Length();  // 点差为向量，取模长
const SCPoint2d n = (q - p).Normalized();
```

- `SCPoint2<T>` / `SCVector2<T>` / `SCBox2<T>`：模板值类型，别名 `SCPoint2d/SCPoint2i`、`SCVector2d/SCVector2i`、`SCBox2d/SCBox2i`
- `SCBox2d`：`MinPoint()`/`MaxPoint()`/`IsValid()`/`Expand(...)`/`AlmostEquals(...)`
- `SCMatrix2d`：`Identity()`、`FromRows`（3D 有、2D 当前缺，见审查记录 L6）、`Inverse()`（奇异返回零矩阵）
- `SCTransform2d`：`Identity()`、`Translation(v)`、`Scale(origin, ratio)`、`Apply(point/vector)`、`Inverse() -> std::optional<SCTransform2d>`（不可逆返回 `std::nullopt`）

### 7.2 图元（`Geometry2d`）

```cpp
#include "Geometry2d/ISCSegment2d.h"      // 抽象接口
#include "Geometry2d/SCLineSegment2d.h"
#include "Geometry2d/SCArcSegment2d.h"
#include "Geometry2d/SCLine2d.h"
#include "Geometry2d/SCCircle2d.h"
#include "Geometry2d/SCEllipse2d.h"
#include "Geometry2d/SCRectangle2d.h"
#include "Geometry2d/SCPolyline2d.h"
#include "Geometry2d/SCPolygon2d.h"
#include "Geometry2d/SCMultiPolyline2d.h"
#include "Geometry2d/SCMultiPolygon2d.h"
```

- `ISCSegment2d`：线段/圆弧的抽象基类，提供 `Kind()`/`IsValid()`/`StartPoint()`/`EndPoint()`/`Length()`/`Bounds()`/`PointAt(param)`/`PointAtLength(dist, clamp)`/`DebugString()`/`Clone()`
- `SCLineSegment2d(start, end)`、`SCArcSegment2d(center, radius, startAngle, sweepAngle, SCArcDirection)`
- `SCLine2d`：`FromOriginAndDirection(origin, dir)` / `FromTwoPoints(a, b)`，`PointAt(param)`，`IsValid()`（方向非退化）
- `SCPolyline2d`：`Open/Closed` 折线。构造：`SCPolyline2d(points, SCPolylineClosure::Open)` 或 `SCPolyline2d(segments, closure)`
  - `PointCount()`/`VertexCount()`（当前等价）、`SegmentCount()`、`Length()`、`PointAt(index|parameter)`、`PointAtLength(dist, clamp)`、`SegmentAt(i)`（返回新 clone）、`Bounds()`
  - ⚠️ `PointAt` 存在整型（索引）与浮点（弧长参数）重载，字面量类型决定语义：`PointAt(0)` 是索引、`PointAt(0.0)` 是参数
- `SCPolygon2d`：`outerRing` + `holes`。`OuterRing()`/`HoleAt(i)`/`HoleCount()`/`Area()`/`Perimeter()`/`Centroid()`/`Bounds()`
- `SCMultiPolygon2d` / `SCMultiPolyline2d`：`Count()`/`Polygons()`/`Polylines()`/`Data()`（别名）/`Find(...)` 等容器接口

### 7.3 二维服务（`Core` + `Geometry2d`）

```cpp
#include "Core/Intersection.h"
#include "Core/Relation.h"
#include "Core/Measure.h"
#include "Core/Projection.h"
#include "Core/Boolean.h"
#include "Core/Offset.h"
#include "Geometry2d/SCPathOps.h"
#include "Geometry2d/SCBoxTree2d.h"
#include "Geometry2d/SCSegmentSearch2d.h"
```

**相交**（`Geometry::Intersect`）：

```cpp
const SCLineSegment2d a(SCPoint2d(0,0), SCPoint2d(2,2));
const SCLineSegment2d b(SCPoint2d(0,2), SCPoint2d(2,0));
const auto hit = Intersect(a, b);
if (hit.HasIntersection()) {
    // hit.kind == SCIntersectionKind2d::Point / Overlap / Tangent
    // hit.points[0].point, hit.pointCount
}
// 其他重载：线-线、线-线段、线段-圆弧、圆弧-圆弧、ISCSegment2d-ISCSegment2d、折线-折线、折线-线段
const auto ext = IntersectExtended(a, b, SCExtensionPolicy::ExtendBoth);  // 延长线相交
```

**关系 / 包含**（`Core/Relation.h`、`Core/Results.h`）：

```cpp
#include "Core/Relation.h"
// Relate(first, second) -> PolygonContainment2d（Brep/Topology.h 提供 SCPolygon2d 版本）
// LocatePoint(...) 等
```

**布尔**（`Core/Boolean.h`）：

```cpp
const SCMultiPolygon2d merged   = Intersect(a, b);   // 交
const SCMultiPolygon2d combined = Union(a, b);       // 并
const SCMultiPolygon2d cut      = Difference(a, b);  // 差
```

**偏移**（`Core/Offset.h`）：

```cpp
const SCOffsetOptions2d options{ /* miterLimit = 4.0 */ };
const SCPolygon2d grown  = Offset(polygon, 0.5, options);
const SCPolyline2d slim  = Offset(polyline, -0.25, options);
```

**路径操作**（`SCPathOps`）：`CutPolygon(...)`、`BuildMultiPolygonByLines(...)`、`NormalizePolygonByLines(...)` 等，结果类型 `SCPolygonCutResult2d`（带 `success`）。

**搜索**（`SCBoxTree2d`/`SCKDTree2d`/`SCSegmentSearch2d`）：

```cpp
SCSegmentSearch2d search;
search.Add(lineSeg);
search.Add(arcSeg);
const auto nearest = search.Nearest(point);            // 最近线段
const auto within  = search.QueryWithinDistance(point, radius);
```

> ⚠️ `SCBoxTree2d/SCKDTree2d` 当前每次查询全量重建（名不副实），大量动态增删的场景性能不符合"树"的预期，见审查记录 H4。

## 8. 三维能力

### 8.1 值类型与线性代数（`Types/Geometry3d`，header-only）

```cpp
#include "Types/Geometry3d/SCPoint3.h"
#include "Types/Geometry3d/SCVector3.h"
#include "Types/Geometry3d/SCDirection3d.h"
#include "Types/Geometry3d/SCBox3.h"
#include "Types/Geometry3d/SCLine3d.h"
#include "Types/Geometry3d/SCLineSegment3d.h"
#include "Types/Geometry3d/SCRay3d.h"
#include "Types/Geometry3d/SCPlane.h"
#include "Types/Geometry3d/SCMatrix3d.h"
#include "Types/Geometry3d/SCTransform3d.h"
#include "Types/Geometry3d/SCIntervald.h"
#include "Types/Geometry3d/SCTriangle3d.h"

using Geometry::SCPoint3d;
using Geometry::SCVector3d;

const SCPlane plane = SCPlane::FromPointAndNormal(SCPoint3d(0,0,0), SCVector3d(0,0,1));
const double dist = plane.SignedDistanceTo(SCPoint3d(0,0,5));  // 5.0
```

- `SCVector3<T>`：`Dot`/`Cross`/`Length`/`Normalized`；`SCDirection3d` 用角度容差比较（`AlmostEquals(other, angleEps)`）
- `SCMatrix3d`：`Identity()`、`FromRows(...)`、`Transpose()`、`Determinant()`、`Inverse()`（奇异返回零矩阵，见审查记录 H3）
- `SCTransform3d`：`Identity()`/`Translation(v)`/`Scale(origin, ratio)`/`Apply(...)`；`Inverse()` 当前在不可逆时返回单位变换（无法区分失败），见审查记录 H3

### 8.2 曲线与曲面（`Geometry3d`）

```cpp
#include "Geometry3d/ISCCurve3d.h"
#include "Geometry3d/SCLineCurve3d.h"
#include "Geometry3d/SCNurbsCurve3d.h"
#include "Geometry3d/ISCSurface.h"
#include "Geometry3d/SCPlaneSurface.h"
#include "Geometry3d/SCNurbsSurface.h"
#include "Geometry3d/SCRuledSurface.h"
#include "Geometry3d/SCOffsetSurface.h"
#include "Geometry3d/SCCurveOnSurface.h"
#include "Geometry3d/TriangleMesh.h"
```

- `ISCCurve3d` 接口：`ParameterRange()`/`IsClosed()`/`IsPeriodic()`/`PointAt(t)`/`Evaluate(t, order)`/`Bounds()`/`Clone()`
- `SCLineCurve3d`（解析）、`SCNurbsCurve3d(degree, controlPoints, knots, periodic)`——⚠️ 当前**无权重**（实为 B-spline），`Evaluate` 导数为有限差分
- `ISCSurface` 接口：`Evaluate(u,v,order)` 返回 `SCSurfaceEval3d`（点/一阶偏导/法线）；`SCPlaneSurface` 为平面
- `SCCurveOnSurface`：独立类（uv 曲线为 `SCPolyline2d`），**不是** `ISCCurve3d`，通用曲线算法无法直接接收它，见审查记录 M25
- `TriangleMesh`：`VertexCount()`/`TriangleCount()`/`VertexAt()`/`TriangleAt()` 等

### 8.3 三维服务

```cpp
#include "Core/Intersection.h"     // 线-面/线-曲线/线-体/面-面等
#include "Core/Projection.h"
#include "Core/Relation.h"
#include "Geometry3d/SCBoxTree3d.h"
#include "Geometry3d/SCSegmentSearch3d.h"
```

```cpp
const auto linePlane = Intersect(line, plane);                    // SCLinePlaneIntersection3d
const auto lineBody  = Intersect(line, brepBody);                 // SCLineBrepBodyIntersection3d
const auto pp        = ProjectPointToBrepBody(point, brepBody);   // 投影（Core/Projection.h）
const auto loc       = LocatePoint(point, polyhedronBody);        // 点包含判定
```

容差统一传 `SCGeometryTolerance3d`；`SCSegmentSearch3d` 当前是线性扫描实现。

## 9. BRep / Polyhedron / Mesh / Section

### 9.1 拓扑

```cpp
#include "Brep/SCBrepBody.h"      // Body -> Shell -> Face -> Loop -> Coedge -> Edge/Vertex
#include "Brep/PolyhedronBody.h"  // 平行平面实体：PolyhedronBody -> PolyhedronFace3d -> PolyhedronLoop3d
```

- `SCBrepBody`：值语义（`vertices_/edges_/shells_` 三向量 + 索引引用），`VertexCount()`/`EdgeCount()`/`ShellCount()`/`FaceCount()`/`VertexAt(i)`/`EdgeAt(i)`/`ShellAt(i)`/`Vertices()`/`Edges()`/`Shells()`/`Bounds()`/`IsValid(tolerance)`
- ⚠️ 拓扑访问器（`ShellAt`/`FaceAt`/`OuterLoop`/`HoleAt`）当前按值返回，遍历即深拷贝，见审查记录 H10
- `PolyhedronBody(faces)`：`FaceCount()`/`FaceAt(i)`/`Faces()`/`Bounds()`/`IsValid(eps)`

### 9.2 转换

```cpp
#include "Brep/BrepConversion.h"
// PolyhedronBody <-> SCBrepBody、mesh 转换；带 issue 枚举的结果（BrepConversionIssue3d）
```

### 9.3 布尔（BodyBoolean）——⚠️ 能力边界

```cpp
#include "Brep/BodyBoolean.h"
// IntersectBodies / UnionBodies / DifferenceBodies
```

当前支持**可确认几何等价或相离的直线边闭体、轴对齐盒内含/重叠、面连通轴对齐盒并集、代表性接触**，以及**不含重合支撑平面的单 shell、直线边平面凸多面体正体积相交**（包括旋转盒）。几何等价同时比较 face 支撑面和边界环，不以拓扑计数或包围盒近似。开口、非流形、边曲线端点与拓扑顶点不一致，或平面 face 的边界未落在支撑平面上的 body 返回 `InvalidInput`；曲线边界（即使两个 body 相同或相离）、重合支撑平面、低维接触、非凸/多 shell body，以及一般并集和差集返回 `UnsupportedOperation`。使用前请确认输入满足支持范围，完整契约见 `review-remediation/d4-body-boolean-capability-matrix.md`。

### 9.4 修复（Healing）

```cpp
#include "Brep/Healing.h"
// Heal(...) 面向 SCBrepBody / PolyhedronBody / TriangleMesh 的修复链路
```

⚠️ `Heal(PolyhedronBody)` 当前为无操作空实现（校验通过原样返回），`Heal(TriangleMesh)` 的封口/定向结果取"先成功者"，见审查记录 M9/L12。

### 9.5 网格

```cpp
#include "Brep/MeshConversion.h"   // ConvertToTriangleMesh（Polyhedron/Brep -> TriangleMesh）
#include "Brep/MeshOps.h"          // 邻接/壳分析等
#include "Brep/MeshRepair.h"       // 定向、封口等
#include "Brep/Tessellation.h"     // ⚠️ 当前仅支持 SCPlaneSurface
```

### 9.6 平面截切（Section）

```cpp
#include "Core/Section.h"

const SCPlane cutPlane = SCPlane::FromPointAndNormal(SCPoint3d(0,0,0), SCVector3d(0,0,1));
const auto section = Section(body, cutPlane);   // body: PolyhedronBody 或 SCBrepBody
if (section.success) {
    // section.contours  ：封闭/开放轮廓（SCSectionPolyline3d）
    // section.segments  ：切割线段
    // section.polygons  ：2D 面域多边形（在切平面坐标系）
    // section.origin/uAxis/vAxis：切平面局部坐标系
}

// 进一步重建：
const auto faces  = RebuildSectionFaces(section);       // 重建 Polyhedron 面
const auto brep   = RebuildSectionBrepBody(section);    // 重建 SCBrepBody
const auto meshes = ConvertSectionToTriangleMeshes(section);
const auto topo   = BuildSectionTopology(section);      // 轮廓父子拓扑树
const auto kind   = ClassifySectionContent(section);    // Empty/Curve/Area/Mixed
```

当前 gap：一般非流形拼接、开放曲线面域裁剪、多层 boundary-attached 开放曲线裁决（见 [test-capability-coverage.md](test-capability-coverage.md)）。

## 12. 已知限制与差距

来源：[test-capability-coverage.md](test-capability-coverage.md) 与 [session-handoff.md](session-handoff.md)，均为当前仍有效的差距：

- `Section`：一般非流形轮廓拼接、超出显式 vertex-touch/edge-touch 子集的开放曲线面积归并、非邻接共面片段合并、多层 boundary-attached 开放曲线裁决
- `Healing`：多 shell shared-boundary/shared-edge 裁决的一般情形、复杂开放 shell 与网格/实体联动修复
- `SearchPoly`：更丰富的 fake-edge 解释、更完整的 ambiguous recovery
- `BodyBoolean`：更一般的 touching/overlap 子集、shell-policy 高阶裁决
- 算法边界：`TangentPoints` epsilon 敏感边界分类、扩展相交的退化重叠分类、折线交点端点去重稳定性、3D 零长段投影边界、3D 等距平局裁决

## 13. 常见问题与注意事项

| 现象 | 说明 |
|------|------|
| 读取 `Geometry::kPi` 等常量得到奇怪值 | DLL 消费者未定义 `GEOMETRY_USE_DLL`，见 §4.4 |
| 类型名称写成无前缀别名 | 当前公开类型保留 `SC` 前缀，例如 `SCPoint2d`、`SCVector3d`；请以 `Geometry.h` 或对应模块头为准 |
| `SCTransform3d::Inverse()` 不可逆时返回的是"单位变换" | 当前无法用返回值区分失败，需配合 `linear.IsInvertible(eps)` 判断（见审查记录 H3） |
| `polyline.PointAt(0)` 与 `polyline.PointAt(0.0)` 语义不同 | 整型=索引，浮点=弧长参数，注意字面量类型（见审查记录 M7） |
| 修改 `SCBrepBody` 困难 | 拓扑访问器只读、按值返回；编辑需走 `BrepEditing` 的复制-重建-替换 |
| 断言/越界行为不一致 | 不同类对越界索引的处理（抛异常/assert/静默）不统一，调用前先 `IsValid`/判空 |
