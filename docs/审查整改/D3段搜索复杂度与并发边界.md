# D3 段搜索复杂度与并发边界

核对日期：2026-11-03。依据 `Source/Core/SCSegmentSearch2d.cpp`、`SCSegmentSearch3d.cpp` 及其公开头推导；本说明不是性能基准或数据竞争检测结果。盒树自身的边界见 [H4空间索引接口变更说明](H4空间索引接口变更说明.md)。

## 查询成本

令 n 为保存条目数，r 为通过筛选的命中数，k' = min(k,r)。几何有效性、包围盒、求交及投影不是一律常数成本，尤其三维曲线可为 NURBS 或用户子类；下表的容器成本须另外加上实际调用的几何计算成本。哈希查找使用标准容器的平均成本，不据此承诺最坏常数时间。

| 入口 | 二维段搜索 | 三维段搜索 |
|---|---|---|
| 半径 | 扫描 n 条目，最多投影 n 次；结果空间 O(r) | 可信包围盒时先按搜索盒查询，再对候选投影；不可信盒、无穷半径或无法构造搜索盒时扫描全部条目 |
| Nearest | 扫描 n 条目，最多投影 n 次，命中暂存 O(1) | 委托 QueryKNearest(point,1,...)，不能据此承诺单次对数查询 |
| KNN | 扫描及投影后收集全部 r 个候选；nth_element 平均 O(r)，最终排序 O(k' log(k'+1))，暂存 O(n)；k 为零仍经过当前扫描路径 | 可信盒使用候选数量扩张，不可信盒则逐条投影、排序并截取；最坏可访问全部条目 |
| 盒相交 | 按当前段几何包围盒逐条筛选，最坏扫描 n 条目 | 可信盒走盒树并过滤曲线有效性；不可信盒回退按当前曲线包围盒扫描，结果按条目顺序整理 |

三维可信盒 KNN 从 min(k,n) 个盒开始，未满足停止条件时将候选数量约倍增，最多扩张到 n；非空且 k>0 时盒树查询轮数为 O(log(n+1))。每轮重新执行盒树 KNN，而不是复用上轮的树遍历；`projectedIds` 保证同一 ID 至多投影一次。总成本包含每轮盒树查询成本之和、哈希检查、候选选择及最终排序，不能只计算最后一轮或只按 k 次投影估算。选择使用 nth_element，其线性成本是平均保证。

三维候选的距离排序按投影点的一阶距离进行；最终投影入口要求成功载荷有效，平方距离不可表示的结果不能作为成功命中。本次核查确认该入口会校验完整结构容差，未发现忽略容差的自定义曲线能够绕过最终投影校验的证据。此结论不扩大一般曲线投影的最优性或可表示范围。

## 内存、修改和并发

查询的结果、候选、哈希集合与遍历状态为调用局部数据；三维 KNN 的临时存储最坏 O(n)，还须加上所调用几何算法自身的临时存储。常驻内存也取决于向量 capacity、树节点及曲线对象大小，不能只由删除后的 Size 推断。三维 Remove 会重建索引，不能当作单次哈希删除；重复 ID 或不可信缓存盒可能改变查询路径。

二维 Entries 返回可写引用，三维 Entries 仅返回只读引用；这些引用都不是快照。Add、Remove、Clear、赋值及析构与任何访问并发时必须同步，二维通过 Entries 的修改同样受此约束。

三维缓存盒的可信性在添加或重建时建立，并非每次查询都重算验证。底层曲线经其他别名在查询之间发生变化时，也不能继续假定缓存有效；调用方应保持被索引几何不变，或用更新后的几何重新构造索引。二维盒查询虽按当前几何计算边界，其距离查询仍受条目有效性及缓存盒有效性规则约束，不能据此宣称两个索引均提供可变几何的自动同步。

索引对象不被修改还不足以单独证明段搜索线程安全：查询会调用共享段／曲线的虚方法。调用者必须同时保证底层几何及其共享资源生存期、无并发写入，并保证用户子类的 const 方法本身可并发调用。shared_ptr<const ...> 不排除其他可写别名或子类的 mutable 缓存。不能把盒树的四线程只读回归直接作为任意曲线子类的线程安全证明。
