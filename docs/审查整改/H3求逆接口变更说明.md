# H3 求逆接口变更说明

## 变更范围

本次变更统一 2D/3D 矩阵和仿射变换的求逆失败语义。以下接口均改为返回 `std::optional`：

- `SCMatrix2d::Inverse`
- `SCMatrix3d::Inverse`
- `SCTransform2d::Inverse`
- `SCTransform3d::Inverse`

本次允许直接修改接口，不保留旧返回类型的兼容重载。产品端需要在调用处显式判断返回值。

## 新接口契约

成功时返回包含逆矩阵或逆变换的 `std::optional`；失败时返回 `std::nullopt`。失败条件包括：

- 输入矩阵包含非有限值；
- `eps` 为负值或非有限值；
- 行列式绝对值小于或等于传入的 `eps`；
- 2D 矩阵直接计算的行列式为非有限值，或 2D/3D 求逆结果包含非有限值；
- 仿射变换的线性部分求逆失败，或平移及逆变换结果包含非有限值。

`eps` 仍使用原有默认值 `Geometry::kDefaultEpsilon`，并按绝对行列式阈值判断奇异性。2D 矩阵沿用直接行列式计算，逆矩阵元素分别除以行列式，避免行列式倒数先溢出；3D 矩阵以尾数和指数表示余子式、行列式及阈值比较，并用补偿项保留乘积舍入误差，允许行列式数值超出 `double` 范围但逆矩阵仍有限的输入。成功结果的平移部分按 `-inverseLinear * translation` 计算。

零矩阵和单位变换不再作为失败哨兵。调用方必须检查 `Inverse(eps)` 的 `has_value()`。`SCMatrix2d/3d::IsInvertible(eps)` 均与各自求逆结果一致；`SCMatrix3d::Inverse(eps)` 在中间运算中保留尾数和指数，仅在形成最终结果时转换为 `double`，避免直接余子式乘法的溢出及列归一化时丢失非零元素。`Determinant()` 仍返回按原公式直接计算的 `double` 值，极端尺度下可能发生中间溢出或下溢，不应作为求逆成功的判据。

## 产品端替换方式

原先的直接赋值：

```cpp
const SCTransform3d inverse = transform.Inverse();
```

替换为：

```cpp
const std::optional<SCTransform3d> inverse = transform.Inverse();
if (!inverse.has_value())
{
    // 按产品业务处理不可逆输入
    return;
}
Use(*inverse);
```

只需要临时使用结果时，也可以写成：

```cpp
if (const auto inverse = transform.Inverse())
{
    Use(*inverse);
}
```

矩阵接口的替换方式相同：

```cpp
const auto inverse = matrix.Inverse();
if (!inverse)
{
    return;
}
const SCMatrix3d identityCandidate = matrix * *inverse;
```

## 受影响文件

- `Include/Types/Geometry2d/SCMatrix2d.h`
- `Include/Types/Geometry2d/SCTransform2d.h`
- `Include/Types/Geometry3d/SCMatrix3d.h`
- `Include/Types/Geometry3d/SCTransform3d.h`
- 使用上述接口的产品代码、测试和示例代码

`std::optional` 定义在标准头 `<optional>` 中，调用方不应依赖其他头的间接包含。

## 验收依据

能力测试覆盖 2D/3D 奇异矩阵和奇异变换返回 `std::nullopt`、无效容差及非有限输入、2D 行列式过阈值但逆矩阵非有限及次正规行列式可逆、3D 变换求逆往返，以及 3D 矩阵在极端尺度下的求逆、奇异判定、中间溢出、同列极小值下溢、行列式大数抵消和乘积舍入残差回归；非奇异 2D 矩阵逆运算改为显式解包。仓库规则禁止 AI 执行构建和测试，实际编译与运行结果需由人工构建流程确认。
