# BodyBoolean 能力边界

调用方可通过 `GetBodyBooleanCapabilities3d()` 查询当前实现的能力声明。`generalBrepCsg` 为 `false`；布尔函数仍返回 `BodyBooleanResult3d`，应先检查 `issue`，再读取 `body`、`bodies` 或 `producedEmptyResult`。

所有操作要求有效、闭合、单 shell 的流形体，边缘须为直线，边端点和面边界须与支撑几何一致。`PolyhedronBody` 入口先转换为 B-rep；曲边、多 shell 和一般非凸相交不在当前能力范围内。

| 输入关系 | 交集 | 并集 | 差集 |
| --- | --- | --- | --- |
| 几何等价 | 原体 | 原体 | 空集 |
| 包围盒相离 | 空集 | 两个体（`bodies`） | 左体 |
| 两个轴对齐盒 | 包含、正体积交叠及低维接触空集 | 包含、单盒结果、面相连正交盒结果；仅棱/点接触返回两个体 | 结果为单盒或空集、外部面/棱/点接触保持左体 |
| 无共面面片的凸多面体正体积相交 | 单个闭合体 | 不支持 | 不支持 |

表中“支持”仅表示相应几何关系能够被当前确定性分支识别，不是对任意组合形体的保证。输入无效时返回 `InvalidInput`；有效但不属于这些子集时返回 `UnsupportedOperation`。`operateOnShells` 和 `preserveInputOrientation` 尚不扩展能力边界。
