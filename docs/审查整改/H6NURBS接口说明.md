# NURBS 接口说明

`SCNurbsCurve3d` 和 `SCNurbsSurface` 现支持每个控制点一个正且有限的权重。旧构造函数继续产生单位权重的非有理 B-spline；新构造函数在 knot 向量后传入 `std::vector<double> weights`，可通过 `Weights()` 读取。曲面权重与控制点都按 `v * controlPointCountU + u` 展平。

参数域分别是 `[knots[degree], knots[controlPointCount]]`。`PointAt` 和 `Evaluate` 将域外参数夹到端点；端点导数使用域内单侧解析值。knot 向量须有限、非递减，参数域须有正长度，权重数量须匹配控制点数量，且每个权重必须大于零。重节点允许存在；在内部重节点处导数取右侧值，最右端点取左侧值。曲线 `Evaluate` 支持到二阶，曲面支持到一阶偏导。

求值时按当前参数处参与计算的权重和控制点坐标分别缩放，再计算有理点和解析导数。这样共同放大或缩小权重不会仅因加权分子的中间值溢出或下溢而改变有限结果。若实际点或导数超出 `double` 可表示范围，接口仍无法保证有限结果。

在参数端点等零基函数位置，点值计算跳过不参与点值的控制点；一阶导数的常规加权累加发生溢出、下溢或明显相消时，改按控制点与当前点值之差计算，并拆分乘除法的二进制指数，保留数学上仍为有限值的导数。参数域右端若有重复 knot，使用其左侧最后一个非零区间求端点值和单侧导数。

二阶导数的常规计算若产生非有限中间值或明显相消，会改按控制点相对当前点值的二阶基函数贡献，以及一阶导数与权重一阶变化的贡献计算；零一阶导数项不参与乘法，避免端点极端权重造成 `0 × inf`。

`IsPeriodic()` 仍反映构造函数传入的周期标志；该标志不自动周期延拓参数。调用方需要周期参数行为时，应自行在参数域内折返参数。
