# H7 三角化接口变更说明

公共导出函数从 `Triangulate(const SCPolygon2d&)` 改为 `Triangulate(const SCPolygon2d&, double tolerance = kDefaultEpsilon)`。默认参数使原有单参数源码调用继续成立，但导出符号已经变化；使用共享库的调用方必须用新头文件重新编译并重新链接。此次不保留旧符号。

需要控制容差时，显式传入非负且有限的 `tolerance`；`0.0` 表示严格零容差，负值或非有限值返回 `std::nullopt`。入口使用该值验证直线段环的连接、短边、自交与孔关系，并进行耳切和孔桥接；弧线段环不属于此三角化入口的输入范围。短边可小于 `SCPolyline2d::IsValid()` 使用的默认容差，只要它大于调用方传入的容差且满足其余几何约束即可。返回的三角形索引仍指向原始展平边界顶点，顺序为外环、`HoleAt(0)`、`HoleAt(1)` 等；环方向不改变索引含义。

耳切和三角形内点判断使用点到边的距离与 `tolerance` 比较；叉积的面积量不再直接与长度容差比较。因此整体尺寸很小、但边长与顶点到对边距离均大于容差的三角形可以正常返回。

内部轮廓适配和多面体面投影会逐顶点建环，不再由 `SCPolyline2d` 的默认闭环构造规则合并接近首点的末端顶点。网格转换按传入的容差调用三角化；无效边界仍返回失败结果。

`MeshConversion`、`MeshRepair` 和 `PolygonTopology` 已改用此入口。调用方应检查 `std::optional` 是否有值，并在切换头文件后重新编译依赖这些模块的二进制文件。
