# H8/H9 算法契约说明

## 线网重建与多边形切割

`BuildMultiPolygonByLinesWithDiagnostics` 是 `SCPathOps` 与 `SearchPolygons` 共用的重建策略入口。两者采用相同的自动闭合、自动延长、假边总开关和分支清理回退选项；`SearchPolygons` 继续在重建结果上提供候选排名及每条推断边的解释。输入线网的线段数、顶点数、悬挂端点数和分支顶点数来自同一诊断结果；`SCSearchPolyDiagnostics2d` 保持原有独立公开结构体，字段值由共享诊断结果复制，兼容已有前向声明。`usedAutoClose`、`usedAutoExtend` 记录本次重建实际执行的修复步骤，不能据输入拓扑和开关推测。原 `BuildMultiPolygonByLines` 保留默认策略及原返回类型。

`removeBranches` 控制初次重建失败后的分支叶边清理回退。正常重建中的悬挂边剔除仍属于环提取的基础清理。`allowFakeEdges=false` 同时禁止自动闭合、自动延长和需要补边的分支回退。

`CutPolygonParts` 与兼容入口 `CutPolygon` 共用布尔裁剪路径，有孔、无孔和凹多边形执行相同规则。切割方向为 `cutter.startPoint` 到 `cutter.endPoint`，沿其无限直线划分左右区域；输出保留每侧所有连通分量。切线端点须有效，其长度统一由调用者的 `eps` 判断，不受 `SCLineSegment2d::IsValid()` 的默认容差影响。多边形无效、切割方向长度不大于 `eps`、长度无法用有限数表示或任一侧没有有效面积时，`CutPolygonParts` 返回 `nullopt`，`CutPolygon` 返回 `success=false` 且两侧为空。`eps` 必须为有限正数。

## NURBS 曲线求交

`IntersectAllPlaneCurveWithStatus` 和 `IntersectAllLineCurveWithStatus` 按曲线参数升序返回已验证的交点。原 `Intersect` 接口继续只返回一个交点；对支持隔离的 NURBS 曲线，它返回多根结果中的第一项。状态接口的 `HasResult` 表示至少找到一个满足距离容差的点；只有 `evidence.negativeCompleteness=Verified` 才表示搜索已穷尽。`Unknown` 表示当前预算、数值精度或曲线类型不足以证明没有其他根，已找到的点仍保留在 `hits` 中。受支持的 NURBS 曲线若存在非零长度重合区间，返回 `NonUnique`；解析直线曲线依据直线与平面的解析关系判定连续重合，即使有限曲线两端均落入距离容差内，穿越平面仍返回单个交点。其他曲线类型沿用有限搜索，不能保证识别连续重合。

对两端夹持、次数为 1 至 16、权重为正的 NURBS 曲线，先按 knot span 分成 Bézier 区间，再利用齐次控制点的平面距离包围区间剪枝和二分。每个候选根的细化限制在其隔离区间内，并以曲线实际点重新验证。切触根可通过导数驻点补查，导数退化时仍可由控制点包围区间定位。近根按参数容差与局部阶数对应的距离分辨率合并；因此距离容差无法分开的根可能合并，并将完整性标为 `Unknown`。超出深度或搜索预算、无法达到要求距离容差时也标为 `Unknown`，不会把未验证点作为交点。

直线与 NURBS 曲线求交先在包含直线的两个互相独立的平面上隔离候选根，再按实际点到直线的距离验证。两个平面分别与不同区间重合时，额外验证 knot 边界上的孤立交点，并保持完整性 `Unknown`。非夹持、高于 16 次或非 NURBS 曲线沿用有限初值搜索；这类结果始终保留完整性未知的声明。`IntersectAllLineSurfaceWithStatus` 会收集不同初值盆地中的已验证曲面交点。平面曲面的解析结果可声明穷尽；一般曲面仍受有限初值预算约束，极窄特征及全局多根穷尽尚无证明，完整性保持 `Unknown`。曲面投影继续使用现有预算和状态接口；调用方应检查其结果证据。
