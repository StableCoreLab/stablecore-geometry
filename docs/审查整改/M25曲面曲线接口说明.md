# M25 曲面上的曲线接口说明

`SCCurveOnSurface` 现实现 `ISCCurve3d`。原有 `SupportSurface()`、`UvCurve()`、`UvPointAt(size_t)` 和整数索引形式的 `PointAt` 保留；通过 `ISCCurve3d&` 可以调用通用投影与求交接口。保留的曲面曲线专用重载继续返回 UV 坐标及线段编号等额外信息。

## 参数与几何

- 参数范围为 `[0, UvCurve().SegmentCount()]`。整数参数对应 UV 顶点，`i + t` 对应第 `i` 条 UV 直线段上的比例 `t`；闭合路径的最后一段回到第一个顶点。
- `UvAt(double)` 和通用 `PointAt(double)` 采用同一分段插值。旧 `PointAt(size_t)`／`PointAt(int)` 仍按顶点索引访问，调用者应使用 `double` 实参表示连续参数。
- 当前模型只接受由直线段组成的有效 UV 路径；曲线段 UV 输入会由 `IsValid()` 拒绝。非平面支撑曲面的 UV 路径还须位于支撑曲面的参数域内。
- `Evaluate(..., 1)` 通过曲面一阶导数与 UV 线段方向计算曲线一阶导数。UV 顶点处采用后继线段的方向，终点采用最后一段方向。一般曲面缺少二阶导数接口，因此请求二阶时最多返回一阶。
- `Bounds()` 对平面支撑采用映射后的顶点包围盒；对其他曲面采用支撑曲面的包围盒，保证曲线在合法参数域内时不会被过窄的顶点包围盒错误裁剪。

`SCCurveOnSurface` 的闭合判定使用三维端点及距离容差；它不承诺跨 UV 顶点的一阶导数连续，因此 `IsPeriodic()` 返回 `false`。`Clone()` 深拷贝支撑曲面。

## 兼容与验证

新增虚基类改变 `SCCurveOnSurface` 的对象布局；使用旧二进制的消费者需要重新编译。测试 `CurveOnSurfaceInterfaceTest` 覆盖通用基类调用、参数、导数、闭合、参数域、包围盒和克隆；`SCGeometry.PackageConsumer` 从安装包编译并运行通用曲线调用。现有曲面曲线专用投影测试继续覆盖原有 UV 结果语义。
