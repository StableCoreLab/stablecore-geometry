# M25 曲面上的曲线接口说明

当前状态（2026-11-05）：任意 ISCCurve2d 接入与原参数分片已实现，详见文末“任意二维 UV 接入与参数分片”。中间章节的直线 UV 限制、局部助手及对应门禁数量保留为各阶段记录，不能据其判断当前模型仍仅接受直线；一般数值完整性仍未关闭。

`SCCurveOnSurface` 现实现 `ISCCurve3d`。原有 `SupportSurface()`、`UvCurve()`、`UvPointAt(size_t)` 和整数索引形式的 `PointAt` 保留；通过 `ISCCurve3d&` 可以调用通用投影与求交接口。保留的曲面曲线专用重载继续返回 UV 坐标及线段编号等额外信息。

## 参数与几何

- 通用参数范围保留实际 ISCCurve2d 的 ParameterRange。旧折线仍为 `[0, UvCurve().SegmentCount()]`，`i + t` 对应第 i 段的比例 t；其他模型通过 UvParameterAt(piece, local) 映射回原参数。
- UvAt(double) 与通用 PointAt(double) 使用实际二维曲线求值。旧折线的整数 PointAt 仍访问顶点；非折线模型没有该视图并显式抛出 std::logic_error。调用者应使用 double 实参表示连续参数。
- 当前模型接受有效的任意 ISCCurve2d，旧折线适配器也可包含圆弧。非平面支撑曲面的 UV 保守盒须完全位于支撑曲面参数域内。
- Evaluate(..., 1) 通过曲面与二维 UV 一阶导数作链式求导。旧折线整数接缝采用后继段，终点采用最后一段；其他模型遵从自身求值契约。二阶请求最多返回一阶，非有限导数不标记为已提供。
- Bounds() 对平面支撑映射 UV 保守盒四角，任一映射角点不可表示则返回无效盒；其他曲面继续采用支撑曲面的保守盒，覆盖曲线内部极值。

`SCCurveOnSurface` 的闭合判定使用三维端点及距离容差；它不承诺跨 UV 顶点的一阶导数连续，因此 `IsPeriodic()` 返回 `false`。Clone() 深拷贝支撑曲面和实际 UV 模型。

通用单结果投影、直线求交和平面求交在目标动态类型为 `SCCurveOnSurface` 时复用曲面曲线专用数值内核。通用结果参数通过 UvParameterAt(segmentIndex, segmentParameter) 还原到原参数域；旧折线等价于 segmentIndex + segmentParameter，专用结果继续提供 UV、线段编号和段内参数。通用投影的最优性证据沿用专用内核的解析完整性结论；通用单结果直线／平面求交的状态和证据沿用专用状态入口，命中与未命中均保留未证明穷尽的语义。

通用多结果直线／平面求交现逐条 UV 分片收集并按曲线参数排序，合并相邻线段在同一参数端点的重复命中。平面支撑的线段映射为三维直线段并复用直线曲线求交；平面求交的完整性沿用各段解析证明，直线求交只在各段提供证明时声明完整。非平面 NURBS 支撑上的轴向 UV 线段构造等价的有理 NURBS 限制曲线，复用现有多根求交内核，随后映射回 UV 段参数并用原曲面逐点验证；回归覆盖同一采样格内三个根、有理权重及反向 U/V 线段。非夹持曲面的轴向段也按 knot 片限制为端点夹持的 Bezier 曲线，避免直接使用非夹持曲线时退回单结果搜索。斜向 UV 线段按 U/V knot 交点拆段，对各 knot 片插入 knot 后取得齐次 Bezier 控制网，再经两轴区间限制及 Bernstein 乘积构造各段的有理限制曲线；非夹持曲面还在有效参数域两端插入 knot，必要时按控制点一致性降阶。回归覆盖单片及跨片的同格三根、有理权重、反向参数、非单位 knot 域、整段重合，以及夹持和非夹持曲面两轴 knot 插入后的曲面等价性。直接 NURBS 曲线根隔离已移除 32 次入口限制，使用动态控制点及既有搜索预算；斜向限制曲线构造也已移除 32 次限制，Bernstein 乘积系数改用最大项起始的相邻比递推并归一化。18 次有理限制曲线的同格三根回归先复现只返回一根，再通过候选间中点的平面距离检查保留可区分根；32 次有理限制曲线的单根回归覆盖上限边界。其他非平面线段仍逐段收集采样区间内已验证的候选；同号采样区间的局部极值会继续细化，以识别切触根和落在同一采样间隔内的窄双根，端点邻近区间也纳入搜索。直线求交还通过两个包含目标直线的平面提供候选，再逐点验证到直线的距离。缺少原控制凸包等独立分离证明时，限制曲线构造数值失败或根隔离预算耗尽仍不能保证找到所有根，因此整体完整性保持 `Unknown`，完整根隔离仍待处理。

## 兼容与验证

限制曲线构造与 M28 曲面曲线长度测量现共用内部 UV 段 knot 分片参数计算；两处均按 U、V knot 生成有序且去重的参数断点。该复用保持现有求交完整性状态语义，高次数与预算耗尽时仍报告 `Unknown`。

独立复审修正 NURBS 曲线多结果平面／直线求交的空结果证据：根隔离无法证明穷尽时，`state` 与 `evidence.hit` 均为 `Unknown`；只有已证明无交点时才使用 `NoResult` 与 `NotApplicable`。近容差带而曲线本身未命中的二次曲线回归先复现两入口证据冲突，修复后与已证明分离的曲线对照通过。该次证据修正不改变当时的次数边界，也不把预算耗尽视为完整搜索。

进一步复审 NURBS 曲线的直线多结果求交：辅助平面上的候选点若无法可靠投影至目标直线，原实现仍继承平面搜索的完整性证明并报告 `NoResult`。现仅在每个平面候选均完成投影及坐标核验后继承负结果完整性；不可表示的候选使外层状态及命中证据保持 `Unknown`。极端坐标回归先复现误报，对照场景确认可验证的离线点仍返回 `NoResult`。该修复不扩展高次数及预算耗尽时的根隔离能力。

新增虚基类改变 `SCCurveOnSurface` 的对象布局；使用旧二进制的消费者需要重新编译。测试 `CurveOnSurfaceInterface3dTest` 覆盖通用基类调用、参数、导数、闭合、参数域、包围盒、克隆以及通用与专用单结果和状态证据的一致性；`SCGeometry.PackageConsumer` 从安装包编译并运行通用曲线调用。现有曲面曲线专用投影测试继续覆盖原有 UV 结果语义。

直接 NURBS 曲线的多根隔离和单结果入口现不再以 32 次为界退回采样搜索。40 次曲线的严格分离证明、非均匀有理权重下的平面／直线双根，以及单结果入口返回最小参数命中均有公开回归；原入口限制下两项回归先失败，移除限制后通过。此结论不覆盖任意次数下的数值完整性：既有深度、参数分辨率及单元数量预算继续生效，无法证明穷尽时仍报告 Unknown；曲面斜向限制曲线构造的次数限制已在后续归一化递推整改中移除，见下文。

斜向限制曲线的 Bernstein 乘积系数现从最大项向两侧递推，以系数和为 1 归一化，避免分别计算巨大二项式系数；原 32 次构造限制及其内部常量头已删除。40 次有理限制曲线在六个参数点与原曲面求值一致，平面单根验证通过；600+600 次系数的有限性、非负性、归一、对称及均值回归覆盖二项式中间量原本不可表示的范围。次数与索引必须可表示，数值失败仍回退为未证明完整，不能把移除次数限制当作任意次数完整性证明。

根隔离中的共面／共线证据现追溯到原始活动控制包。knot 插入或 de Casteljau 细分后的全零数值可能由下溢产生，不能单独证明重合区间；缺少原始共面证据时，仍用原曲线核验候选并保持未知完整性。直线入口的两个辅助平面汇合也使用同一证据，避免将数值变零误报为 NonUnique。

曲面上曲线投影也复用 NURBS 限制曲线：将通用曲线投影候选映射回 UV 段，并在原曲面重新求值计算距离；保留既有采样候选与数值失败回退。投影请求严格的段参数域，部分轴向 UV 段不使用覆盖整域的轴向快速结果，而由 Bezier／knot 分片构造准确限制。正反向映射均按有向参数区间计算。此复用同时覆盖 B-rep trim 边界投影；非平面支撑的全局最优性继续为 `Unknown`，不把限制曲线投影候选视为完备证明。窄双谷回归先复现目标点在曲线上仍出现约 `1.4e-4` 距离误差，修复后覆盖六组位置、部分轴向／斜向段及正反方向。

一次限制曲线按非零 knot span 复用解析线段投影，先选取解析距离最小的候选，再根据相邻齐次权重还原 knot 参数并回代一次原曲面，避免把数千段折线送入非线性多初值搜索。权重先按最大值缩放，回代仍以原曲面为准；退化线段或不可表示结果沿用既有回退。高阶限制曲线使用通用曲线投影。此次复审通过既有 10,000 span 的实体预算用例识别出首版新增开销，并据此补齐一次曲线分支；不能将该分支的解析性扩大为所有非平面曲面曲线的最优性证明。

限制曲线参数到 UV 段参数的有向映射已集中在内部 `RestrictedNurbsSurfaceCurve::ToSegmentParameter`，投影、直线求交和平面求交共用原有 lerp 与区间比值公式。投影仍先检查限制片局部参数，求交仍检查映射后的段参数并在原曲面重新求值核验；两类检查的适用范围保持原样。未增加隐式夹取或改变构造失败、预算耗尽及一般曲面的 Unknown 完整性，本次只消除三处映射公式重复。

## 原始控制凸包的平面分离证明

平面与 NURBS 支撑曲面上曲线的多结果入口，现先检查支撑曲面的原始控制点。完整输入验证已保证有限控制点、合法参数结构及正权重；有效参数域内的有理曲面处于控制点凸包内。如果所有控制点到目标平面的有符号距离均有限、严格超过线性容差且同号，可直接证明整张支撑曲面及其曲面上曲线与平面分离，返回 `NoResult`、`NotApplicable` 命中证据和 `Verified` 负结果完整性，原因标志为 None。

这条证明不依赖限制曲线构造或采样，也不由插 knot、细分后数值变零推导。控制点分处两侧、接触容差带或距离不可表示时，不启用此证明，继续原限制曲线与回退路径；一般非平面完整性仍可能为 Unknown。该平面证明不自动扩展到投影或任意曲面；直线入口后续通过包含直线的分离平面复用该证明，见下节。

`SeparatedNurbsSurfaceControlHullProvesPlaneMiss` 在两侧及单位／非均匀正权重共四组场景先复现 Unknown，再验证已证明分离；`MixedSurfaceControlHullDoesNotProvePlaneMiss` 对照确认全控制包跨侧时不因当前 UV 路径没有交点就宣称完整。既有 x=2 平面分离用例同步使用更精确的负结果证据，原多根命中的 Unknown 完整性断言保留。扫描控制点增加 O(控制点数) 成本，不替代一般根隔离。

## 包含目标直线的分离平面

直线多结果入口现复用上述原控制凸包检查。优先选择方向最大分量以外的两个坐标轴，再尝试其余坐标轴；用原直线方向与坐标轴叉乘构造至多三个经过直线原点、包含目标直线的平面。叉乘只涉及原方向与 0／1，不构造方向平方或大分量间的乘积。任一有效平面将全部原控制点严格分离到容差带外同一侧，即证明整张支撑曲面与直线分离；返回 NoResult、NotApplicable 命中、Verified 负结果完整性及 None 原因。

平面构造无效或三个原控制包检查均不能证明分离时，继续原候选与回退路径，不从当前 UV 路径的采样空结果推断完整性。投影和一般求交完整性不因该证明自动提升。最多三次控制点扫描，额外成本为 O(控制点数)。

`SeparatedSurfaceControlHullProvesObliqueLineMiss` 先复现 Unknown，再覆盖分别由两个辅助平面证明分离的两组控制包，以及反向、普通和 1e200 大尺度斜方向共六组输入。`MixedSurfaceControlHullDoesNotProveLineMiss` 确认全控制包跨侧时，即使当前 UV 路径无命中仍保留 Unknown。

第三坐标轴对应的平面也可能提供独立分离证据：`ThirdCoordinatePlaneProvesSurfaceLineMiss` 的控制包在先前两个平面上跨侧，而在第三平面上严格同侧，三组反向／普通／1e200 方向回归先失败后通过。与方向平行的坐标轴产生零法向时，该平面仍被有效性检查跳过。三个平面都不能证明分离不表示控制凸包一定与直线相交，也不能据此关闭一般根隔离问题。

## 分离证明的数值边界回归

原控制包分离用例进一步加入整体权重尺度 1e-300、1e300；与单位、普通非均匀权重及平面两侧共八组输入均保持已证明分离。证明使用原控制点的空间位置，不构造权重与大坐标的齐次乘积。

`ControlHullAtToleranceBoundaryDoesNotProveSeparation` 用可精确表示的线性容差 0.125 检查所有控制点恰在容差带边界时不能证明无交点；允许内核返回已验证命中或非唯一结果，不强制一种共面分类。`UnrepresentableControlPlaneDistanceKeepsCompletenessUnknown` 使用有限控制坐标 -1e308 与有限平面原点 +1e308，验证坐标差不可表示时仍保留 Unknown 状态、Unknown 命中及负结果完整性，不能把无穷距离当作严格分离证据。本次仅补验收用例，生产证明逻辑未变。

## 部分 UV 段的重合证据边界

轴向限制曲线的完整参数域可能大于当前 UV 段。离散根可以在参数映射后过滤，但内核的 NonUnique 结果没有一组可逐点过滤的离散根，不能把整域中其他位置的重合直接提升为当前 UV 段重合。

平面、直线多结果求交与投影现均要求限制曲线构造严格覆盖当前 UV 段。AxisRestrictionIgnoresOverlapOutsideUvSegment 用 U 域前半段重合、后半段离开的两片线性 NURBS 曲面，检查正反 UV 方向：仅取后半段时保持 Unknown 且无命中；仅取前半段的部分区间时仍为 NonUnique。前一对照修复前在平面和直线入口均误报 NonUnique，回归先失败后通过。无独立证明时的构造失败、预算耗尽及一般完整性边界继续保留。

## 候选去重的共同中点检查

平面与直线求交候选现共用内部 CurveOnSurfaceIntervalWithinTolerance，统一参数邻近判断与原曲面中点求值；调用方再分别检查平面有符号距离，或直线投影参数有效性及距离。此助手只供有效结构容差、有限候选参数下的去重使用，不是整个参数区间重合或搜索完整性的证明。直线分支继续保留距离较小的候选，平面分支保留原 unique 顺序。

原先保留的 max(parameterEpsilon, 1e-8) 现已有公开复现，改为两个候选各按调用者 parameterEpsilon 给定参数邻域，合并条件要求参数差不超过 2 * parameterEpsilon，并继续要求原曲面中点处于调用者空间容差内。没有独立的绝对参数下限；parameterEpsilon 为零时仅相同参数可通过参数检查。两个候选区间的相接规则是去重策略，不是对各数值求解器误差界的严格证明。

ParameterDeduplicationPreservesDistantNearbyRoots 构造 z(t)=t*(t-4e-9)、x(t)=1e9*t 的二次有理曲线及其等价曲面限制曲线：两个真实根参数相差约 4e-9，空间位置相距约 4；调用者 parameterEpsilon=1e-12、distanceEpsilon=5e-18，中点仍在距离容差内。旧固定下限把曲面曲线的两根合成一根，直接 NURBS 对照返回两根；新规则在正反 UV 方向及平面／直线公开入口均保留两根。X 坐标断言按 1e9 * parameterEpsilon 换算误差界，而不是要求求解器超出调用者参数精度。

移除绝对下限后，专项复审发现单份 parameterEpsilon 会让既有切点产生两份相差约 1.23e-9 的候选；采用两个候选参数邻域相接规则后，CurvedSingleUvSegmentFindsOffGridTangency 的单结果回归继续通过，47 项专项测试通过。空间中点检查仍只证明该中点在容差内，不据此关闭整段重合或一般根隔离的未知完整性。

本批共同助手由原有回归及两配置完整门禁验收，1054 项登记、1038 项执行通过、16 项既有禁用；不新增重复实现的镜像测试。前节 SHA256 是上一阶段的库快照，本次助手收敛后库文件已重新生成。

## 输入齐次控制量的可表示性

限制曲线构造的 Bezier 路径、knot 细分路径和轴向快速路径现共用 CheckedHomogeneousSurfaceControl。权重归一化或轴向 basis 加权后必须仍为有限正值；非零坐标乘以权重得到零，或乘积非有限时，停止该限制构造，不允许后续插值把已丢失信息的控制量当作原始控制包证据。

LostSurfaceWeightsDoNotProvePlaneOverlap 的原始控制点与权重均有限，原权重严格为正。极端权重比和小坐标乘积分别覆盖权重、坐标的下溢，斜向部分 UV 段及完整 U／V 轴向段共六组输入；构造失败后允许采样提供已验证的容差内命中，但不能报 NonUnique，负结果完整性保持 Unknown。最初的斜向权重下溢负例在修复前误报 NonUnique，先失败后通过。
