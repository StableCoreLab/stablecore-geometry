# M25 曲面上的曲线接口说明

`SCCurveOnSurface` 现实现 `ISCCurve3d`。原有 `SupportSurface()`、`UvCurve()`、`UvPointAt(size_t)` 和整数索引形式的 `PointAt` 保留；通过 `ISCCurve3d&` 可以调用通用投影与求交接口。保留的曲面曲线专用重载继续返回 UV 坐标及线段编号等额外信息。

## 参数与几何

- 参数范围为 `[0, UvCurve().SegmentCount()]`。整数参数对应 UV 顶点，`i + t` 对应第 `i` 条 UV 直线段上的比例 `t`；闭合路径的最后一段回到第一个顶点。
- `UvAt(double)` 和通用 `PointAt(double)` 采用同一分段插值。旧 `PointAt(size_t)`／`PointAt(int)` 仍按顶点索引访问，调用者应使用 `double` 实参表示连续参数。
- 当前模型只接受由直线段组成的有效 UV 路径；曲线段 UV 输入会由 `IsValid()` 拒绝。非平面支撑曲面的 UV 路径还须位于支撑曲面的参数域内。
- `Evaluate(..., 1)` 通过曲面一阶导数与 UV 线段方向计算曲线一阶导数。UV 顶点处采用后继线段的方向，终点采用最后一段方向。一般曲面缺少二阶导数接口，因此请求二阶时最多返回一阶。
- `Bounds()` 对平面支撑采用映射后的顶点包围盒；对其他曲面采用支撑曲面的包围盒，保证曲线在合法参数域内时不会被过窄的顶点包围盒错误裁剪。

`SCCurveOnSurface` 的闭合判定使用三维端点及距离容差；它不承诺跨 UV 顶点的一阶导数连续，因此 `IsPeriodic()` 返回 `false`。`Clone()` 深拷贝支撑曲面。

通用单结果投影、直线求交和平面求交在目标动态类型为 `SCCurveOnSurface` 时复用曲面曲线专用数值内核。通用结果参数按 `segmentIndex + segmentParameter` 表示，专用结果继续提供 UV、线段编号和段内参数。通用投影的最优性证据沿用专用内核的解析完整性结论；通用单结果直线／平面求交的状态和证据沿用专用状态入口，命中与未命中均保留未证明穷尽的语义。

通用多结果直线／平面求交现逐条 UV 线段收集并按曲线参数排序，合并相邻线段在同一参数端点的重复命中。平面支撑的线段映射为三维直线段并复用直线曲线求交；平面求交的完整性沿用各段解析证明，直线求交只在各段提供证明时声明完整。非平面 NURBS 支撑上的轴向 UV 线段构造等价的有理 NURBS 限制曲线，复用现有多根求交内核，随后映射回 UV 段参数并用原曲面逐点验证；回归覆盖同一采样格内三个根、有理权重及反向 U/V 线段。非夹持曲面的轴向段也按 knot 片限制为端点夹持的 Bezier 曲线，避免直接使用非夹持曲线时退回单结果搜索。斜向 UV 线段按 U/V knot 交点拆段，对各 knot 片插入 knot 后取得齐次 Bezier 控制网，再经两轴区间限制及 Bernstein 乘积构造各段的有理限制曲线；非夹持曲面还在有效参数域两端插入 knot，必要时按控制点一致性降阶。回归覆盖单片及跨片的同格三根、有理权重、反向参数、非单位 knot 域、整段重合，以及夹持和非夹持曲面两轴 knot 插入后的曲面等价性。直接 NURBS 曲线根隔离已移除 32 次入口限制，使用动态控制点及既有搜索预算；斜向限制曲线构造也已移除 32 次限制，Bernstein 乘积系数改用最大项起始的相邻比递推并归一化。18 次有理限制曲线的同格三根回归先复现只返回一根，再通过候选间中点的平面距离检查保留可区分根；32 次有理限制曲线的单根回归覆盖上限边界。其他非平面线段仍逐段收集采样区间内已验证的候选；同号采样区间的局部极值会继续细化，以识别切触根和落在同一采样间隔内的窄双根，端点邻近区间也纳入搜索。直线求交还通过两个包含目标直线的平面提供候选，再逐点验证到直线的距离。限制曲线构造数值失败或根隔离预算耗尽时仍不能保证找到所有根，因此整体完整性保持 `Unknown`，完整根隔离仍待处理。

## 兼容与验证

限制曲线构造与 M28 曲面曲线长度测量现共用内部 UV 段 knot 分片参数计算；两处均按 U、V knot 生成有序且去重的参数断点。该复用保持现有求交完整性状态语义，高次数与预算耗尽时仍报告 `Unknown`。

独立复审修正 NURBS 曲线多结果平面／直线求交的空结果证据：根隔离无法证明穷尽时，`state` 与 `evidence.hit` 均为 `Unknown`；只有已证明无交点时才使用 `NoResult` 与 `NotApplicable`。近容差带而曲线本身未命中的二次曲线回归先复现两入口证据冲突，修复后与已证明分离的曲线对照通过。该次证据修正不改变当时的次数边界，也不把预算耗尽视为完整搜索。

进一步复审 NURBS 曲线的直线多结果求交：辅助平面上的候选点若无法可靠投影至目标直线，原实现仍继承平面搜索的完整性证明并报告 `NoResult`。现仅在每个平面候选均完成投影及坐标核验后继承负结果完整性；不可表示的候选使外层状态及命中证据保持 `Unknown`。极端坐标回归先复现误报，对照场景确认可验证的离线点仍返回 `NoResult`。该修复不扩展高次数及预算耗尽时的根隔离能力。

新增虚基类改变 `SCCurveOnSurface` 的对象布局；使用旧二进制的消费者需要重新编译。测试 `CurveOnSurfaceInterfaceTest` 覆盖通用基类调用、参数、导数、闭合、参数域、包围盒、克隆以及通用与专用单结果和状态证据的一致性；`SCGeometry.PackageConsumer` 从安装包编译并运行通用曲线调用。现有曲面曲线专用投影测试继续覆盖原有 UV 结果语义。

直接 NURBS 曲线的多根隔离和单结果入口现不再以 32 次为界退回采样搜索。40 次曲线的严格分离证明、非均匀有理权重下的平面／直线双根，以及单结果入口返回最小参数命中均有公开回归；原入口限制下两项回归先失败，移除限制后通过。此结论不覆盖任意次数下的数值完整性：既有深度、参数分辨率及单元数量预算继续生效，无法证明穷尽时仍报告 Unknown；曲面斜向限制曲线构造的次数限制已在后续归一化递推整改中移除，见下文。

斜向限制曲线的 Bernstein 乘积系数现从最大项向两侧递推，以系数和为 1 归一化，避免分别计算巨大二项式系数；原 32 次构造限制及其内部常量头已删除。40 次有理限制曲线在六个参数点与原曲面求值一致，平面单根验证通过；600+600 次系数的有限性、非负性、归一、对称及均值回归覆盖二项式中间量原本不可表示的范围。次数与索引必须可表示，数值失败仍回退为未证明完整，不能把移除次数限制当作任意次数完整性证明。

根隔离中的共面／共线证据现追溯到原始活动控制包。knot 插入或 de Casteljau 细分后的全零数值可能由下溢产生，不能单独证明重合区间；缺少原始共面证据时，仍用原曲线核验候选并保持未知完整性。直线入口的两个辅助平面汇合也使用同一证据，避免将数值变零误报为 NonUnique。
