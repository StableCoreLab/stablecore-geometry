# M25 曲面上的曲线接口说明

`SCCurveOnSurface` 现实现 `ISCCurve3d`。原有 `SupportSurface()`、`UvCurve()`、`UvPointAt(size_t)` 和整数索引形式的 `PointAt` 保留；通过 `ISCCurve3d&` 可以调用通用投影与求交接口。保留的曲面曲线专用重载继续返回 UV 坐标及线段编号等额外信息。

## 参数与几何

- 参数范围为 `[0, UvCurve().SegmentCount()]`。整数参数对应 UV 顶点，`i + t` 对应第 `i` 条 UV 直线段上的比例 `t`；闭合路径的最后一段回到第一个顶点。
- `UvAt(double)` 和通用 `PointAt(double)` 采用同一分段插值。旧 `PointAt(size_t)`／`PointAt(int)` 仍按顶点索引访问，调用者应使用 `double` 实参表示连续参数。
- 当前模型只接受由直线段组成的有效 UV 路径；曲线段 UV 输入会由 `IsValid()` 拒绝。非平面支撑曲面的 UV 路径还须位于支撑曲面的参数域内。
- `Evaluate(..., 1)` 通过曲面一阶导数与 UV 线段方向计算曲线一阶导数。UV 顶点处采用后继线段的方向，终点采用最后一段方向。一般曲面缺少二阶导数接口，因此请求二阶时最多返回一阶。
- `Bounds()` 对平面支撑采用映射后的顶点包围盒；对其他曲面采用支撑曲面的包围盒，保证曲线在合法参数域内时不会被过窄的顶点包围盒错误裁剪。

`SCCurveOnSurface` 的闭合判定使用三维端点及距离容差；它不承诺跨 UV 顶点的一阶导数连续，因此 `IsPeriodic()` 返回 `false`。`Clone()` 深拷贝支撑曲面。

通用单结果投影、直线求交和平面求交在目标动态类型为 `SCCurveOnSurface` 时复用曲面曲线专用数值内核。通用结果参数按 `segmentIndex + segmentParameter` 表示，专用结果继续提供 UV、线段编号和段内参数。通用投影的最优性证据沿用专用内核的解析完整性结论；通用单结果直线／平面求交的状态和证据沿用专用状态入口，命中与未命中均保留未证明穷尽的语义。

通用多结果直线／平面求交现逐条 UV 线段收集并按曲线参数排序，合并相邻线段在同一参数端点的重复命中。平面支撑的线段映射为三维直线段并复用直线曲线求交；平面求交的完整性沿用各段解析证明，直线求交只在各段提供证明时声明完整。非平面 NURBS 支撑上的轴向 UV 线段构造等价的有理 NURBS 限制曲线，复用现有多根求交内核，随后映射回 UV 段参数并用原曲面逐点验证；回归覆盖同一采样格内三个根、有理权重及反向 U/V 线段。非夹持曲面的轴向段也按 knot 片限制为端点夹持的 Bezier 曲线，避免直接使用非夹持曲线时退回单结果搜索。斜向 UV 线段按 U/V knot 交点拆段，对各 knot 片插入 knot 后取得齐次 Bezier 控制网，再经两轴区间限制及 Bernstein 乘积构造各段的有理限制曲线；非夹持曲面还在有效参数域两端插入 knot，必要时按控制点一致性降阶。回归覆盖单片及跨片的同格三根、有理权重、反向参数、非单位 knot 域、整段重合，以及夹持和非夹持曲面两轴 knot 插入后的曲面等价性。直接 NURBS 曲线根隔离已移除 32 次入口限制，使用动态控制点及既有搜索预算；斜向限制曲线构造也已移除 32 次限制，Bernstein 乘积系数改用最大项起始的相邻比递推并归一化。18 次有理限制曲线的同格三根回归先复现只返回一根，再通过候选间中点的平面距离检查保留可区分根；32 次有理限制曲线的单根回归覆盖上限边界。其他非平面线段仍逐段收集采样区间内已验证的候选；同号采样区间的局部极值会继续细化，以识别切触根和落在同一采样间隔内的窄双根，端点邻近区间也纳入搜索。直线求交还通过两个包含目标直线的平面提供候选，再逐点验证到直线的距离。缺少原控制凸包等独立分离证明时，限制曲线构造数值失败或根隔离预算耗尽仍不能保证找到所有根，因此整体完整性保持 `Unknown`，完整根隔离仍待处理。

## 兼容与验证

限制曲线构造与 M28 曲面曲线长度测量现共用内部 UV 段 knot 分片参数计算；两处均按 U、V knot 生成有序且去重的参数断点。该复用保持现有求交完整性状态语义，高次数与预算耗尽时仍报告 `Unknown`。

独立复审修正 NURBS 曲线多结果平面／直线求交的空结果证据：根隔离无法证明穷尽时，`state` 与 `evidence.hit` 均为 `Unknown`；只有已证明无交点时才使用 `NoResult` 与 `NotApplicable`。近容差带而曲线本身未命中的二次曲线回归先复现两入口证据冲突，修复后与已证明分离的曲线对照通过。该次证据修正不改变当时的次数边界，也不把预算耗尽视为完整搜索。

进一步复审 NURBS 曲线的直线多结果求交：辅助平面上的候选点若无法可靠投影至目标直线，原实现仍继承平面搜索的完整性证明并报告 `NoResult`。现仅在每个平面候选均完成投影及坐标核验后继承负结果完整性；不可表示的候选使外层状态及命中证据保持 `Unknown`。极端坐标回归先复现误报，对照场景确认可验证的离线点仍返回 `NoResult`。该修复不扩展高次数及预算耗尽时的根隔离能力。

新增虚基类改变 `SCCurveOnSurface` 的对象布局；使用旧二进制的消费者需要重新编译。测试 `CurveOnSurfaceInterfaceTest` 覆盖通用基类调用、参数、导数、闭合、参数域、包围盒、克隆以及通用与专用单结果和状态证据的一致性；`SCGeometry.PackageConsumer` 从安装包编译并运行通用曲线调用。现有曲面曲线专用投影测试继续覆盖原有 UV 结果语义。

直接 NURBS 曲线的多根隔离和单结果入口现不再以 32 次为界退回采样搜索。40 次曲线的严格分离证明、非均匀有理权重下的平面／直线双根，以及单结果入口返回最小参数命中均有公开回归；原入口限制下两项回归先失败，移除限制后通过。此结论不覆盖任意次数下的数值完整性：既有深度、参数分辨率及单元数量预算继续生效，无法证明穷尽时仍报告 Unknown；曲面斜向限制曲线构造的次数限制已在后续归一化递推整改中移除，见下文。

斜向限制曲线的 Bernstein 乘积系数现从最大项向两侧递推，以系数和为 1 归一化，避免分别计算巨大二项式系数；原 32 次构造限制及其内部常量头已删除。40 次有理限制曲线在六个参数点与原曲面求值一致，平面单根验证通过；600+600 次系数的有限性、非负性、归一、对称及均值回归覆盖二项式中间量原本不可表示的范围。次数与索引必须可表示，数值失败仍回退为未证明完整，不能把移除次数限制当作任意次数完整性证明。

根隔离中的共面／共线证据现追溯到原始活动控制包。knot 插入或 de Casteljau 细分后的全零数值可能由下溢产生，不能单独证明重合区间；缺少原始共面证据时，仍用原曲线核验候选并保持未知完整性。直线入口的两个辅助平面汇合也使用同一证据，避免将数值变零误报为 NonUnique。

曲面上曲线投影也复用 NURBS 限制曲线：将通用曲线投影候选映射回 UV 段，并在原曲面重新求值计算距离；保留既有采样候选与数值失败回退。投影请求严格的段参数域，部分轴向 UV 段不使用覆盖整域的轴向快速结果，而由 Bezier／knot 分片构造准确限制。正反向映射均按有向参数区间计算。此复用同时覆盖 B-rep trim 边界投影；非平面支撑的全局最优性继续为 `Unknown`，不把限制曲线投影候选视为完备证明。窄双谷回归先复现目标点在曲线上仍出现约 `1.4e-4` 距离误差，修复后覆盖六组位置、部分轴向／斜向段及正反方向。

一次限制曲线按非零 knot span 复用解析线段投影，先选取解析距离最小的候选，再根据相邻齐次权重还原 knot 参数并回代一次原曲面，避免把数千段折线送入非线性多初值搜索。权重先按最大值缩放，回代仍以原曲面为准；退化线段或不可表示结果沿用既有回退。高阶限制曲线使用通用曲线投影。此次复审通过既有 10,000 span 的实体预算用例识别出首版新增开销，并据此补齐一次曲线分支；不能将该分支的解析性扩大为所有非平面曲面曲线的最优性证明。

限制曲线参数到 UV 段参数的有向映射已集中在内部 `RestrictedNurbsSurfaceCurve::ToSegmentParameter`，投影、直线求交和平面求交共用原有 lerp 与区间比值公式。投影仍先检查限制片局部参数，求交仍检查映射后的段参数并在原曲面重新求值核验；两类检查的适用范围保持原样。未增加隐式夹取或改变构造失败、预算耗尽及一般曲面的 Unknown 完整性，本次只消除三处映射公式重复。

## 原始控制凸包的平面分离证明

平面与 NURBS 支撑曲面上曲线的多结果入口，现先检查支撑曲面的原始控制点。完整输入验证已保证有限控制点、合法参数结构及正权重；有效参数域内的有理曲面处于控制点凸包内。如果所有控制点到目标平面的有符号距离均有限、严格超过线性容差且同号，可直接证明整张支撑曲面及其曲面上曲线与平面分离，返回 `NoResult`、`NotApplicable` 命中证据和 `Verified` 负结果完整性，原因标志为 None。

这条证明不依赖限制曲线构造或采样，也不由插 knot、细分后数值变零推导。控制点分处两侧、接触容差带或距离不可表示时，不启用此证明，继续原限制曲线与回退路径；一般非平面完整性仍可能为 Unknown。该平面证明不自动扩展到投影或任意曲面；直线入口后续通过包含直线的分离平面复用该证明，见下节。

`SeparatedNurbsSurfaceControlHullProvesPlaneMiss` 在两侧及单位／非均匀正权重共四组场景先复现 Unknown，再验证已证明分离；`MixedSurfaceControlHullDoesNotProvePlaneMiss` 对照确认全控制包跨侧时不因当前 UV 路径没有交点就宣称完整。既有 x=2 平面分离用例同步使用更精确的负结果证据，原多根命中的 Unknown 完整性断言保留。扫描控制点增加 O(控制点数) 成本，不替代一般根隔离。

## 包含目标直线的分离平面

直线多结果入口现复用上述原控制凸包检查。优先选择方向最大分量以外的两个坐标轴，再尝试其余坐标轴；用原直线方向与坐标轴叉乘构造至多三个经过直线原点、包含目标直线的平面。叉乘只涉及原方向与 0／1，不构造方向平方或大分量间的乘积。任一有效平面将全部原控制点严格分离到容差带外同一侧，即证明整张支撑曲面与直线分离；返回 NoResult、NotApplicable 命中、Verified 负结果完整性及 None 原因。

平面构造无效或三个原控制包检查均不能证明分离时，继续原候选与回退路径，不从当前 UV 路径的采样空结果推断完整性。投影和一般求交完整性不因该证明自动提升。最多三次控制点扫描，额外成本为 O(控制点数)。

`SeparatedSurfaceControlHullProvesObliqueLineMiss` 先复现 Unknown，再覆盖分别由两个辅助平面证明分离的两组控制包，以及反向、普通和 1e200 大尺度斜方向共六组输入。`MixedSurfaceControlHullDoesNotProveLineMiss` 确认全控制包跨侧时，即使当前 UV 路径无命中仍保留 Unknown。

第三坐标轴对应的平面也可能提供独立分离证据：`ThirdCoordinatePlaneProvesSurfaceLineMiss` 的控制包在先前两个平面上跨侧，而在第三平面上严格同侧，三组反向／普通／1e200 方向回归先失败后通过。与方向平行的坐标轴产生零法向时，该平面仍被有效性检查跳过。三个平面都不能证明分离不表示控制凸包一定与直线相交，也不能据此关闭一般根隔离问题。

## 分离证明的数值边界回归

原控制包分离用例进一步加入整体权重尺度 1e-300、1e300；与单位、普通非均匀权重及平面两侧共八组输入均保持已证明分离。证明使用原控制点的空间位置，不构造权重与大坐标的齐次乘积。

`ControlHullAtToleranceBoundaryDoesNotProveSeparation` 用可精确表示的线性容差 0.125 检查所有控制点恰在容差带边界时不能证明无交点；允许内核返回已验证命中或非唯一结果，不强制一种共面分类。`UnrepresentableControlPlaneDistanceKeepsCompletenessUnknown` 使用有限控制坐标 -1e308 与有限平面原点 +1e308，验证坐标差不可表示时仍保留 Unknown 状态、Unknown 命中及负结果完整性，不能把无穷距离当作严格分离证据。本次仅补验收用例，生产证明逻辑未变。
