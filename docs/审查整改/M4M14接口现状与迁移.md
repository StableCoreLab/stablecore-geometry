# M4–M14 接口现状与迁移

本表以当前源码为准核对历史审查项。保留的兼容入口不应被误判为两套独立实现；仍有选择空间的数值或公开接口规则不通过机械改名处理。

| 编号 | 当前证据与结论 | 后续边界 |
|---|---|---|
| M4 | 二维及三维 Point、Vector、Box 均有模板和整数／双精度别名；`SCBox3` 已提供 `operator==`、`AlmostEquals`。浮点点、向量及盒的近似比较现拒绝无效容差，点与向量还拒绝非有限坐标；二维和三维向量长度、二维点间一阶距离用 `std::hypot` 避免平方下溢与提前溢出 | 不为尚无需求的其他三维对象强行模板化 |
| M5 | `SCVector2.h` 已直接定义 `Dot`、`Cross` | 旧辅助头仅保留二维谓词和兼容函数 |
| M6 | `docs/设计/库设计说明.md` 将二维标量容差与三维距离、角度、参数和包围盒容差分开定义；圆弧比较新增距离、角度独立参数，默认角度与参数值有独立命名常量。圆弧的显式 `IsValid(eps)`、`Length(eps)`、`Bounds(eps)` 以线性弧长容差为准，旧无参数入口保留默认角度阈值；基类 `ParameterAtLength(..., epsilon)` 也沿动态圆弧类型使用 `Length(epsilon)`。轴采样与投影现提供显式线性 `epsilon` 重载，旧入口继续使用默认值 | 新接口按量纲选用参数；已有 `double eps` 兼容重载不作无语义依据的删除 |
| M7 | `SCPolyline2d::PointAt(int)` 对负索引抛出 `std::out_of_range`，`VertexAt` 提供显式索引入口；`PointAt(double)` 是弧长比例参数。显式容差的 `LengthAt` 与 `ParameterAtLength` 使用对应的 `Length(eps)` 换算。仓库内部已无整数索引形式的调用点，`PointAt(int)` 与 `PointAt(size_t)` 已标记弃用且继续保留转发 | 新代码按索引用 `VertexAt`，按弧长比例参数用 `PointAt(double)`；旧符号在当前 1.x 保留 |
| M8 | `SCVector2::Normalized` 调用 `TryNormalized`；旧 `TryNormalize` 转发。形状自由函数仍作为成员能力的兼容外观 | 只有出现计算逻辑分叉时再抽取共享内核 |
| M9 | `HoleAt`、`VertexAt`、`PolygonAt` 提供带范围检查的访问；`operator[]` 遵循不检查的下标约定。`CheckedIndexAccessTest` 三项直接回归覆盖首末有效位置、末尾越界、最大 size_t、空状态及 PolygonAt 两种 const／可写重载，异常类型为 `std::out_of_range` | 不把标准风格的 `[]` 改成隐式抛异常入口 |
| M10 | `SCDirection3d::AlmostEquals` 的参数名为 `angleEps`，默认值引用 `kDefaultAngleEpsilon`；改用单位方向的弦长比较，保留极小角度的分辨率；负值及非有限角度无效，大于等于 π 的角度覆盖所有有效方向 | 角度与点、盒等对象的线性距离容差分开；回归用例为 `Direction3dCapabilityTest.AlmostEqualsUsesAngularToleranceAtSmallAngles` |
| M11 | Section 旧类型名与 `StartT`、`EndT` 已标记 `deprecated`，新名称分别为 `*Result3d`、`StartParameter`、`EndParameter` | 旧名在当前 1.x 保留 |
| M12 | 容器的 `Size`、具名集合访问器是主入口；多多边形、多折线、二维盒树、KD 树和二／三维段搜索的九个旧 `Data()` 重载均弃用并转发至 `Polygons()`／`Polylines()`／`Entries()`，三维盒树不新增旧名；`PolygonTopology2d` 与 `SCSectionTopology3d` 也已补齐 `Size()`，原 `Count()` 标记弃用并转发，计数含义与对象布局不变。主要能力测试及共用布尔测试助手的 76 处旧计数调用迁至 `Size()`；仅保留多几何及截面拓扑的四处旧调用以覆盖兼容符号。`SCMatrix2d` 已具备 `FromRows`、`AlmostEquals`、`operator==` | 旧名在当前 1.x 保留；安装后消费者验证拓扑的主计数入口 |
| M13 | `SCSegmentSearch2d::Add` 现有共享指针和基类引用两个入口；三种 `Sample` 重载共用 `SampleSegment`，在分配与求值前校验计数容量；`SampleByMaxAngle` 先检查计数有限性及整数表示范围，边界契约见 Sampling.h | 依据所有权需求选用 Add 入口 |
| M14 | `CutPolygonParts` 以 `std::optional` 返回成功结果；旧 `CutPolygon` 标记 `deprecated` 并共用裁剪实现 | 一般 Boolean 的统一失败证据仍属 D6 范围 |

这些结论只关闭历史审查中已失效的具体指控。M25 的曲面上曲线接口、M28 按具体入口跟踪的容差传播与策略，以及 M29/M30 的专用遍历和索引命中模型仍在 [审查问题修复方案.md](审查问题修复方案.md) 跟踪。

## M31 二维投影标志统一及行为迁移

对非退化有效段，端点形式、具体段及 ISCSegment2d 形式的 isOnSegment 均报告未夹取投影是否在段参数域内（含对应容差）。clampToSegment 仅改变返回点和参数，不把该标志强制置真。默认及显式容差入口使用同一规则。

这是对原 M31 语义不一致的修复：例如线段 (0,0) 至 (4,0)，查询 (6,3) 且夹取时，三种入口均返回点 (4,0)、参数 1 和 isOnSegment=false。此前端点形式会返回 true；依赖该旧标志判断夹取结果的调用者应检查返回参数／点，或使用自身的夹取选项，不再将该标志解释为返回点是否在段上。公开签名与结果布局未改，退化段策略保留。

ProjectionOverloadsPreserveDocumentedMembershipSemantics 沿用原过滤名称，覆盖五位置、两夹取状态及默认／显式容差共 20 组；统一端点标志断言后先复现四处失败。此前记录的保留兼容差异属于旧阶段，不能作为原 M31 已修复的依据。

最终两配置完整 CTest 各 1078 项登记、1062 项执行通过、16 项既有禁用；基础 EndpointSegmentProjectionContracts 的旧夹取标志断言也已迁移，其余断言保留。两轮源码与调用点复核未发现本批新问题。
