# T4 转换场景验收

核对日期：2026-11-04。对照初始审查提交 `9767303` 的 `Test3dConversion.cpp`，原始 `SupportMismatchNearEqual*`、`TinyScale*` 实际共有 53 个场景。下表将每项原构造入口追踪到当前能力测试：每个构造入口在转换测试源码中恰有一处引用，每个当前测试名在 Debug／RelWithDebInfo CTest 发现结果中恰有一项登记。此核对证明场景身份及单次登记，不单独证明断言等价或算法完备；参数化的断言与语句核对记录见执行情况。

同构系列已使用具名参数；共享角扇形与封闭四面体的原点合并共用坐标判据，拓扑数量及闭壳状态作为具名参数明确保留。共享顶点扇形检查顶点平均，小尺度封闭四面体检查闭壳，继续使用各自独立判据。旧过滤名按表迁移，不保证历史 CTest 序号保持。

本轮另将原 `Conversion3dCapabilityTest.NearEqualSharedEdgeVerticesUseRepresentativeAverageTarget` 迁移为 `Conversion3d/SharedEdgeRepresentative3dTest.PreservesRepresentativeAverageTarget/ValidInput`；该有效输入不属于上述两个前缀，因此不计入 53 项原始系列。

当前文件分工：`TestConversionRepresentative3d.cpp` 为共享边／扇形和共享链代表点，`TestConversionClosedRepresentative3d.cpp` 为封闭四面体／棱柱参数组，`TestConversionCuboid3d.cpp` 为长方体参数组，`TestConversionTinyScale3d.cpp` 为小尺度参数组和独立闭壳，`TestConversion3d.cpp` 为一般修复及孔主导共享链。
