## 公共状态契约

新增包装器按 `state`、`payloadValid`、`payload`、`evidence` 的次序定义，复合列表及统计位于其后。默认构造为 `InvalidInput`、无有效 payload，原因含 `InvalidInput`；默认拷贝按值复制 payload、证据及列表，不依赖共享的隐式搜索状态。旧 payload 的字段和旧函数签名保持原状，新增函数由 DLL 导出。

`HasResult` 必须同时具备有效 payload、适用的旧 `success/intersects` 真值及有限字段。`NonUnique` 保留重合事实而不公开唯一点。`NoResult` 仅用于有否定完备性证据的空交集；一般有限搜索未找到根使用 `Unknown`。枚举分类的 `Inside/Outside/OnBoundary`、`Above/Below/OnPlane` 均作为有效 `HasResult` 返回，不能套用空交集状态。

调用方读取距离前先检查操作状态与 `payloadValid`，再检查对应字段有效位；平方下溢得到的有限舍入零仍可读取，但不能证明几何重合。`DistanceWithStatus` 的主字段为一阶距离；`DistanceSquaredWithStatus` 还要求同一候选的平方字段有效。平方上溢不影响一阶距离入口保留有限值。

复合对象先检查现有 `IsValid` 结构契约，失败时整体输入无效。结构有效之后某一面区域未知或数值求值不可用，保留其记录并传播未知；其他有限命中可以保留为 `HasResult`。既有 trim 单独定义几何区域时不借用未经对应验证的 3D edge 作确定拓扑结论。body 投影、求交及定位保留 shell/local/flat 面标识；同一 face 的多个离散根可以重复 flat 编号，逐 hit 证据保持同下标对应。

## 闭壳射线的证明边界

闭合验证建立完整边使用表，检查相反方向的两次使用、面连通、顶点邻接环和重复面。B-rep 额外按真实 `EdgeIndex` 检查两次使用；端点相同但索引不同的边不能凭几何重合拼成闭壳。多 shell 缺少组合角色时保持未知。已有 trim 与拓扑边只在共享 correspondence 验证通过后共同用于闭壳判断。

命中按拓扑顶点或拓扑边身份分组，规范归属取 `(shellIndex, faceIndex, loopIndex, coedgeIndex)` 的字典序最小项。B-rep 使用原顶点/边索引，网格使用原顶点/三角形索引；多面体先按其精确共享顶点构造边关联。合并命中时不使用浮点坐标或线参数作为身份键。每组要求所有关联面都出现，核对实际命中位置和线参数方向；不同拓扑事件不能互相抵消歧义。

固定射线沿 `(1, 0.3713906763541037, 0.52999894000318)`。投影坐标通过 `TwoSum` 与显式 `std::fma` 的浮点展开保存舍入余项；乘积接近下溢或中间量溢出时返回未知。二维定向的常数项、符号扰动 `±(δ,δ²)` 的一次项、二次项依次比较，因此不需要选择有限扰动步长。每个拓扑事件分别核对两个符号侧的穿越奇偶：奇数次是一次横穿，偶数次为切触；两侧不一致或无法证明符号时为未知。展开算术依赖标准舍入及工具链默认的精确浮点模式，不能使用允许代数重排的 fast-math 编译选项。

求交列表中的实际原点命中先核验为 `OnBoundary`，即使局部投影漏掉边界或对象开放也保留。未核验为空间边界的近零线参数返回未知，不按参数阈值直接丢弃后继续计数。

## 已执行的定向验证

- 原 1000 span 曲线内节点求交回归已修复：先判定所有种子的实际位置，避免较早细化得到的近似根遮蔽精确节点。
- 固定 `18×18`、`1e80` workload：最近一次完整 Debug CTest 中位数 `206.005 ms`，p95 `207.346 ms`；位置求值 `3563`，导数求值 `2739`，种子 `1620`，满足独立的 `250/500 ms` 门槛。
- 实际硬预算 workload：10000 个 span，带状态入口的位置求值准确停在 `2,000,000`，导数求值 `23,743`，保留 `HasResult` 与有限候选，最优性为 `Unknown(SearchIncomplete)`。旧投影与旧 `Distance/DistanceSquared` 完成搜索并返回后续更近的结果；状态一阶距离保留同一截断候选。多个独立的新旧入口调用包含在此测试中，不作为单次性能计时。
- 双面实际预算 workload：两个 shell 各含一个 10000 span 的窄面，区域及拓扑对应均可用。两个子搜索各自达到位置 `2,000,000`、导数 `23,743`，均保留候选并单独记录 `SearchIncomplete`；旧 body 投影继续完成搜索。不会把一个 body 总预算误当作每面预算，也不会在子搜索内部重置计数。
- 预算计数边界：位置上限、导数上限、恰好用完但未请求下一次求值、导数耗尽后仍可请求零阶位置，以及旧模式越过新增上限，均有定向断言。
- 状态验证已覆盖距离平方上溢、平方下溢与真实零、无效输入优先级、开放对象实际命中、平面重合与唯一点分流、跨 shell 未知面记录与展平编号、反向 coedge 固有端点，以及大尺度网格有限一阶距离。
- 闭壳共享边/顶点用例覆盖穿顶点、穿边及切触；数值无法稳定决定归属时保持未知。
- 同一共面多边形的多个孤立切触分别保留；连续区间端点不伪装为孤立根。孤立切触与连续区间并存时保留有限列表，同时报告 `NonUnique` 原因及未知的剩余根覆盖。
- B-rep、多面体和焊接网格对穿顶点、穿边及切触采用一致规则；重复几何端点但未共享 B-rep 边索引的壳保持未知，实际边界命中仍可用。
- 新增极大/极小方向的平行与垂直判断、零容差非零向量、跨度溢出的有限参数端点、相邻浮点参数及直纹曲面导数用例。
- 弯曲曲面上的 UV 直线长度与解析积分对照，不再等同于端点弦长。
- 节点跨度 `[-DBL_MAX, DBL_MAX]` 的 NURBS 曲线/曲面保留正确零阶位置及可表示的导数；双线性求值和位置缓存共用同一稳定基函数助手，缓存键中的四个基函数值就是实际 evaluator 输入，不使用另一套近似节点反解。完整活动控制点与权重、固定 degree/evaluator 路径及四个实际基函数值共同确定逐项相同的加权求和；不同 span 的 UV 候选仍独立处理。无效对象或非有限参数的求值位置为无效值，不返回可被误用的默认原点。

## 提交前审查后续事项

平面 trim 边的投影现使用稳定的一阶长度计算解析参数；当端点差值、投影或实际求值不可可靠表示而进入有限采样时，保留可核验候选，并将曲线、面、body 和距离状态入口的最优性传播为 `Unknown(NoProof)`。新增平方边长溢出及解析回退的定向用例。旧记录的源码指纹和性能数字不适用于修改后的工作树。

本轮按用户授权重新生成 VS 解决方案，Debug 与 RelWithDebInfo 均构建成功。首次 Debug 定向 CTest 在用例发现阶段因默认超时中止，未执行断言；将两个 `gtest_discover_tests` 的 `DISCOVERY_TIMEOUT` 设为 60 秒并重新生成后，定向测试通过。随后 Debug 全量 CTest 为 637 项启用测试全部通过、18 项禁用、用时 331.51 秒；RelWithDebInfo 全量 CTest 为 637 项启用测试全部通过、18 项禁用、用时 54.72 秒，均包含包消费者测试。以上运行结果覆盖本次平面 trim 修复，但未重新测量各性能 workload 的十次原始样本；具体摘要见《e49d50f验证原始记录》。

**技术债：实施前相对性能基线 `B` 缺失。**现有材料没有可重建的实施前完整源码快照及各 workload 的十次原始测量，因此原方案的 `1.25B` 求值次数和 `1.5B` p95 相对门槛保持“未验证”，不得以当前快照反推或重命名基线。后续若找不到历史材料，应在继续性能修改前冻结新快照与绝对成本预算，并通过明确的方案变更替换该相对门槛；新快照只能作为后续回归基线，不能证明本轮相对实施前的性能变化。
