## 一、总体结论

库的整体工程健康度是 **中上**：构建与测试基线稳定、Debug/RelWithDebInfo 均为 637 项启用测试通过且 18 项明确禁用；Types 值类型层干净、2D/3D 平行做得用心；Brep 顶层 API 风格（结果结构 + issue 枚举 + 可选返回）统一；无 "not implemented" 抛异常残留。

当前仍有 **1 个必须优先处理的系统性问题**：`Heal(PolyhedronBody)` 是无操作空实现，公共 API 仍会给调用方造成能力已实现的印象。

测试体系仍有结构性缺口：部分测试文件较大，Gaps 中保留明确禁用的未实现能力，且仍有未覆盖的类型和边界场景。

次要但值得注意的：H8 的诊断与分支清理策略仍分层，基于独立拓扑数组的环遍历和模型专用几何算法仍有重复；结果类型和聚合头已经分层，容差与组合接口仍需收敛；历史命名计划和 CI 声明需按当前仓库文件重新核对。

## 二、高危结构问题（发布前必须处理）

### H8. 多边形重建的核心流程已共用，诊断与分支清理仍分层

- **位置**：`Source/Core/SCPathOps.cpp` 的 `BuildMultiPolygonByLines`、`Source/Core/SearchPoly.cpp` 的 `SearchPolygons`；切割逻辑位于 `Source/Core/SCPathOps.cpp` 的 `ComputePolygonCut`
- **描述**：当前 `SearchPolygons` 已调用 `BuildMultiPolygonByLines` 复用线段清理、分割、端点修复、候选环提取和填充构造；两者不再是两套完整重建管线。`SearchPoly` 另有线网分析、候选诊断和分支清理回退流程，这是带诊断的上层策略。原记录所称逐行相同的打分公式及旧行号未能对应当前实现。`CutPolygon` 仍按有洞/无洞分支采用不同裁剪路径。
- **建议**：保留共享的基础重建入口；后续如统一分支清理策略，先明确 `SCSearchPolyOptions2d` 与 `BuildMultiPolygonByLines` 的选项及诊断契约，再抽取可复用的策略层。单独评估 `CutPolygon` 两条路径的语义后再决定是否合并。
- **整改进度**：线网诊断与修复选项已由 `SCPathOps` 共享入口提供，`SearchPolygons` 复用其结果；分支回退已移入共享入口。`CutPolygon` 的有孔、无孔路径已合并为同一布尔裁剪实现，公开返回契约见 [H8H9算法契约说明.md](H8H9算法契约说明.md)。

### H9. 通用求交/投影已改为自适应参数细分与导数细化

- **位置**：`Source/Core/Intersection3d.cpp` 的线-曲线、线-曲面及平面-曲线求交；`Source/Core/Projection3d.cpp` 的曲线与曲面投影
- **描述**：曲线初值按 NURBS 非零 knot span 划分，并依据弦偏差与切向转角自适应细分；曲面初值按 knot span 参数片划分，并依据片内偏差自适应四分；曲线和曲面初值均最多生成 256 个，预算在参数片间分配，超预算时均匀抽取参数片。线-曲线和线-曲面求交对这些初值执行带回溯的导数 Newton；平面-曲线求交使用自适应区间括根与切触 Newton；点-曲线/曲面投影使用同一组自适应参数初值。线-边求交及 B-rep 边投影复用通用曲线入口。细分有最大深度保护，极窄局部特征及切触根仍可能漏检。
- **建议**：继续完善切触根隔离、多根返回契约与奇异点收敛判据；评估基于曲线/曲面包围体的剪枝，以减少自适应初值数量。
- **整改进度**：NURBS 曲线的平面／直线求交已增加控制点包围区间剪枝、切触与奇异根隔离及多根状态接口；直线与曲面增加多盆地已验证命中接口。有限预算、近根合并和一般曲面无法证明穷尽时返回完整性 `Unknown`，具体边界见 [H8H9算法契约说明.md](H8H9算法契约说明.md)。

- M28 SearchPoly 候选契约复审：`SearchPolygons` 能按非默认容差返回窄凹口候选，但 `SCSearchPolyCandidate2d::IsValid()` 仅按默认容差检查；新增带 `epsilon` 的重载，并保留无参数语义。独立复审又发现正无穷面积或合成边周长、NaN 评分仍被判有效，两入口现统一要求指标有限。公开回归先失败后通过；安装包消费者覆盖新入口。
- M28 SearchPoly 评分量纲复审：分支顶点惩罚原按线性修补尺度扣减面积评分，等比缩小 1000 倍后惩罚只缩小 1000 倍；现按修补尺度平方计量。公开等比缩放回归先失败后通过，现有候选排序及解释用例通过。
- M28 盒裁剪回退尺度复审：边长 `1e-8` 的短回退边输入在 `eps=1e-15` 下，固定 `1e-8` 修补阈值使交集为空、差集返回整个原盒；按原始顶点包围盒的较短边限制重建阈值后，三个有效小尺度的交、差、并集回归通过。无效折线的 `Bounds()` 为空，故回退尺度由顶点直接计算。`1e-9` 方盒本身不满足当前有效性规则，未作为本轮成功边界。
- M28 错位小盒并集复审：有效及带短回退边的错位盒在 `eps=1e-15` 下均曾被拆成三个面。差集回退现仅将可修复为四角轴对齐盒的无效输入纳入计算；并集在原结果非单面时，对正面积重叠的盒提取外露边并按调用者容差重建，验证单面面积，公开回归另验证两个缺角点在外。独立复审将扩大容差的盒修复限定于无效输入，防止有效非盒的窄细节被抹除；非盒输入保持原一般路径。
- M28 偏移复审：二维多边形偏移的候选排序和语义方向修复不再把线性 `eps` 直接加到面积上；按面积量纲比较，代表性凹多边形的小尺度外扩与内缩保持原方向。当前用例未复现旧判据导致的错误选面，仍需继续审查复杂候选情形。
- M28 显式偏移容差复审：原 `SCOffsetOptions2d` 按值传递，直接加字段会破坏旧 ABI；现保留其布局并新增四参数重载。边长 `1e-8` 方形的外扩、内缩和多面入口先复现错误结果，微小圆弧内缩先复现结果为空；容差沿调用链传递后回归通过。无效容差统一拒绝；独立复审又封闭无效输入经归一化触发固定阈值重试的路径，安装包消费者覆盖新导出入口。线段本身的默认有效性下限与复杂孔、分裂区域仍待单独收敛。
