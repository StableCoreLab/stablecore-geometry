- M28 结果对象容差有效性：B-rep 编辑与转换、截面重建及网格修复的结果对象现先检查传入容差，失败或空结果不再绕过参数校验；结构容差与线性容差的回归先失败后通过。其余数值结果契约继续审查。
- M6/M10 默认角度容差：`SCDirection3d::AlmostEquals` 的默认参数现引用 `kDefaultAngleEpsilon`，与弧度语义一致；当前数值与原默认常量相同，行为保持不变。

- M28 线段细分参数去重：Boolean／PathOps 共用助手的插入与压缩现统一使用各段换算后的参数容差，修复长段近端点交点被线性 epsilon 吞掉的问题；两种输入顺序回归先失败后通过。既有换算系数及上限和其他容差边界继续审查。

## 修复方案

### D1 模块边界与公开头迁移

`Core/Metrics.h`、`Core/SearchPoly.h`、`Core/Results.h`、`Core/Projection.h` 与 `Core/Intersection.h` 已移除对结果类型聚合头的依赖，直接包含声明所需类型；二维、投影及扩展二维结果头已增加独立编译目标。其他传递包含继续分项收敛。

Measure、Relation、Section 与 Validation 也已移除该聚合依赖；Validation 对截面仅作前置声明，实现文件显式包含完整定义。`Include/Core` 已无算法头直接包含 `Core/GeometryTypes.h`，兼容聚合入口及其他模块边界仍需分别审查。

序列化头已移除旧算法聚合与结果聚合依赖，解除其与 `Geometry.h` 的循环包含，并增加独立编译检查；公共头对结果聚合头的直接包含只保留在唯一聚合入口。

独立编译门禁现复用完整公开头清单，118 个公开头均已验证；由此发现并补齐 `SCRuledSurface.h` 缺失的曲线接口包含。公开头自包含检查不再维护手工子集，其他模块设计边界仍按当前问题继续处理。

当前依赖方向、唯一 umbrella、旧 include 的兼容期及迁移表见 [模块依赖与头文件迁移.md](../设计/模块依赖与头文件迁移.md)。按“基础类型→2D/3D→Brep→Core”继续迁移；旧头保留转发入口，相关公开头增加独立编译检查。

### D2 数值与 API 契约统一

M9 的范围检查补齐直接验收证据：CheckedIndexAccessTest 三项覆盖 VertexAt、HoleAt、PolygonAt 的有效边界、空状态、末尾和最大 size_t 越界；PolygonAt 同时覆盖 const 与可写重载，明确要求 std::out_of_range。生产实现和 operator[] 约定未改，原有测试正文独立比对保留。

统一 2D/3D 的类型泛化、归一化、越界、空结果和容差语义。求逆接口已统一使用 `std::optional`，矩阵与变换的失败条件和容差规则见 [H3求逆接口变更说明.md](H3求逆接口变更说明.md)；本次按要求直接替换接口，不保留旧返回类型兼容层。

M12 拓扑计数遗漏已修复：`PolygonTopology2d` 和 `SCSectionTopology3d` 补齐 `Size()` 主入口，旧 `Count()` 弃用转发，保留符号及计数语义。主要能力测试及共用助手迁移 76 处调用，四处明确的兼容调用继续通过；内部实现与调试输出不再调用旧入口。新增导出入口由安装后消费者验证，Debug 完整 CTest 通过。其他具名计数（如 `PointCount()`、`HoleCount()`）保留其独立含义，旧符号在当前 1.x 保留。

M28/M30 段搜索命中有效性已对齐：`SCSegmentSearchHit2d/3d::IsValid()` 要求点有效、参数有限、平方距离有限且非负；两维的无穷距离及非有限参数回归均先失败后通过。任意有限参数仍允许，不引入统一 `[0, 1]` 参数域或新布局。索引入口实际返回类型及兼容载荷边界已写入 [M29M30遍历与容器说明.md](M29M30遍历与容器说明.md)，其他结果及容差契约继续按当前问题审查。

### D3 空间索引产品语义

新增 [空间索引性能初测](D3空间索引性能初测.md)：三种持久索引、三种规模及独立扫描对照，独占计时且不设机器速度门槛。已有两配置首轮数据，二维盒有序插入构建成本增长显著，不能据查询收益关闭性能验收；预热、重复统计、其他负载和数据竞争检测仍保留。

段搜索的复杂度、候选扩张、向量容量及共享几何并发前提已按当前实现推导，见 [D3段搜索复杂度与并发边界](D3段搜索复杂度与并发边界.md)。明确二维 k=0 仍扫描、三维每轮重查盒树、不可信盒回退，以及用户曲线虚方法线程安全的调用方责任；性能及数据竞争工具验收仍保留。

M28/M30 二维段搜索的半径、最近邻及 KNN 比较改用欧氏距离；平方距离下溢不再导致零半径误命中或错误排序。三个公开回归先失败后通过，13 项相关定向测试通过；载荷平方距离字段及有限值检查、Nearest 的等距遍历顺序和 KNN 的等距 ID 次序保留。此项只解决明确的下溢比较问题，其他容差传播、投影数值范围及 D3 验收继续按原范围处理。

恢复后复审补齐 KD 树精确点查询容差校验：`Query(point, eps)` 拒绝负值、NaN 和无穷容差，零容差仍精确匹配。三节点及删除后的回归先复现无穷容差误匹配，再通过；此项不改变半径查询的正无穷上限规则，也不关闭 D3 的性能及数据竞争验收。

持久索引及 KNN `eps` 语义已在代码和接口变更说明中确定；复杂度、向量容量和并发访问边界已按实现推导并写入 H4 说明，四线程只读功能回归已通过。长期更新一致性、性能基准及数据竞争检测仍需补齐验收证据。使用暴力扫描作为 oracle，覆盖 Add/Remove/Update、KNN、距离和边界行为。

### D4 B-rep 数据模型与布尔能力

L13 的网格查询与修复职责已按当前源码明确，见 [L13网格查询与修复职责](L13网格查询与修复职责.md)。MeshOps 只读查询与 Core/MeshRepair 的副本写入、三角化及策略失败边界已分开；内部三角边枚举已由两实现的四处调用共用层级中立的 `Source/Detail/TriangleEdges3d.h`；原边顺序与方向保持，其他执行语句独立还原比对一致。一般修复能力仍保留，不以职责文档或局部去重关闭这些问题。

确定 `SCBrep`/`Polyhedron` 的主表示、转换边界、拓扑所有权和稳定访问方式。Boolean 能力矩阵已公开，当前一般 CSG、重合支撑面、非凸或多 shell body、曲线边界以及一般并集/差集仍需设计后实现，不能用局部启发式扩展。

### D5 NURBS 与求交/投影数值内核

已采用 rational NURBS，明确权重、参数域、周期标志及导数阶数，并实现共享解析 basis/导数。H9 的曲线根隔离、多根返回、奇异及失败证据已按 [H8H9算法契约说明.md](H8H9算法契约说明.md) 实现；一般曲面仍受有限初值预算约束，完整性不能证明时返回 `Unknown`。曲面上曲线投影已接入严格段域的 NURBS 限制曲线候选，一次限制曲线按 span 复用解析线段投影，高阶限制曲线复用通用投影；原曲面回代校验和未知最优性证据保留。一般曲面及其余投影内核仍需继续收敛。

### D6 2D 多边形重建与布尔内核

基础重建、诊断和分支回退已收敛到 `SCPathOps` 共享入口；`CutPolygon` 两个公开入口共用布尔裁剪与失败模型，详见 [H8H9算法契约说明.md](H8H9算法契约说明.md)。一般 Boolean 的失败模型、epsilon 分层和其他平行实现仍需继续收敛。

继续收敛三角化、采样、环遍历、epsilon 和公共 helper 的重复实现；统一版本与安装目录来源，明确 GTest 离线策略及 shared/static 安装验证；同步 README、命名计划、CI 声明、编码规范和测试覆盖文档。
