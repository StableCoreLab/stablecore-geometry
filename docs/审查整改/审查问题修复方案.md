当前依赖方向、唯一 umbrella、旧 include 的兼容期及迁移表见 [模块依赖与头文件迁移.md](../设计/模块依赖与头文件迁移.md)。按“基础类型→2D/3D→Brep→Core”继续迁移；旧头保留转发入口，相关公开头增加独立编译检查。

代码规范已同步 M12 主计数约定：容器使用 Size()，具名的 PointCount／HoleCount／ShellCount 保留集合含义，弃用 Count 按当前 1.x 转发；更新规范中的失效交接路径，改指向实际结构收敛交接。对照公开声明、迁移说明并核查规范的相对链接后，未发现本次文档修正的新问题。

统一 2D/3D 的类型泛化、归一化、越界、空结果和容差语义。求逆接口已统一使用 `std::optional`，矩阵与变换的失败条件和容差规则见 [H3求逆接口变更说明.md](H3求逆接口变更说明.md)；本次按要求直接替换接口，不保留旧返回类型兼容层。

新增 [空间索引性能初测](D3空间索引性能初测.md)：三种持久索引、三种规模及独立扫描对照，独占计时且不设机器速度门槛。已有两配置首轮数据，二维盒有序插入构建成本增长显著，不能据查询收益关闭性能验收；预热、重复统计、其他负载和数据竞争检测仍保留。

段搜索的复杂度、候选扩张、向量容量及共享几何并发前提已按当前实现推导，见 [D3段搜索复杂度与并发边界](D3段搜索复杂度与并发边界.md)。明确二维 k=0 仍扫描、三维每轮重查盒树、不可信盒回退，以及用户曲线虚方法线程安全的调用方责任；性能及数据竞争工具验收仍保留。

恢复后复审补齐 KD 树精确点查询容差校验：`Query(point, eps)` 拒绝负值、NaN 和无穷容差，零容差仍精确匹配。三节点及删除后的回归先复现无穷容差误匹配，再通过；此项不改变半径查询的正无穷上限规则，也不关闭 D3 的性能及数据竞争验收。

持久索引及 KNN `eps` 语义已在代码和接口变更说明中确定；复杂度、向量容量和并发访问边界已按实现推导并写入 H4 说明，四线程只读功能回归已通过。指定的长期更新序列已有独立扫描 oracle：256 次添加、2560 次更新、穿插与批量删除、清空复用；三类固定负载已有两配置五次重复测量。其他分布、Update 性能、更多查询负载及数据竞争检测仍待验收，不把已有功能与固定负载证据泛称为尚未执行。

### D5 NURBS 与求交/投影数值内核

M25／M28 显式闭合判断已修复默认容差回落：IsClosed(tolerance) 在调用者校验后直接映射 UV 原参数端点，不再通过默认曲线求值重新拒绝小法向支撑面。新回归先失败后通过，默认无效、开放路径及无效容差对照保持；公开求值语义不改，其他具体入口继续验收。

非线性 UV 长度的速度缩放已覆盖两个极端分支：范数溢出时先按分片参数宽度缩放导数分量，再计算范数；次正规数范数且放大因子大于 1 时也先放大分量，避免过早范数舍入丢失分量。总参数宽度不可表示时仍用有限半宽缩放并恢复两倍，普通有限正规数路径保持。LengthScalesDerivativeBeforeOverflowingNorm 的普通／溢出两组导数，以及 LengthPreservesSubnormalDerivativeComponentsBeforeScaling 的有限／溢出宽度两组输入均先失败后通过，相关专项 62 项通过；不据此关闭一般积分误差或根隔离验收。

M25 降阶候选现先检查有限控制量及严格正权重，避免误差比较接受零／负候选后丢弃整条有效限制曲线。零、负候选权重的回归先失败后通过，小正权重的正常降阶对照及两配置完整门禁通过；失败保留原高次表示，不替代一般有理误差验收。

M25 齐次插值现显式返回 optional，检测内部同侧非零凸组合下溢成零；限制、插 knot、轴向细分和降阶均传播失败，避免丢失信息后误报重合。公开负例先失败后通过，真实端点、相消及插 knot 失败对照与两配置完整门禁通过；其余相消、参数换算及一般数值完整性仍需验收。

M25／M28 降阶重建比较已移除最小正规数的绝对尺度下限，按各齐次分量自身尺度比较；可表示的次正规数曲率不再被误降阶。普通、小尺度及次正规数的曲率／直线对照先失败后通过，两配置完整门禁通过。一般有理误差和其余数值损失仍继续验收。

M25 Bernstein 乘积项现于累加前检查加权坐标和齐次权重的可表示性，拒绝非零乘积下溢等信息损失，防止数值变零导致虚假的平面重合证据。denorm_min 高度的单位权重曲面公开回归先失败后通过，两配置完整门禁通过；累加相消、插 knot 和降阶的其他误差仍待验收。

M25 输入齐次控制量现由三处限制构造共用可表示性检查，拒绝权重或非零坐标乘积下溢等数值损失，防止混合后虚假证明平面重合。公开六组回归及两配置完整门禁通过；后续插值、knot 插入及反齐次运算的其他损失仍待验收，构造失败回退的未知完整性继续保留。

M25 的平面／直线候选去重共用参数邻近及中点求值助手，各自空间距离核验和候选选择保留。原绝对参数下限 1e-8 已有公开回归复现误合并空间相距约 4 的两个近参数根；现按两个调用者参数邻域相接采用 2 * parameterEpsilon，无绝对下限，中点空间判据保留。新回归覆盖正反 UV 方向及两类公开求交入口，既有切点单结果继续通过，47 项专项通过。不将共同助手或中点检查当作整区间重合及一般根隔离证明，见 M25 曲面曲线接口说明。

M25 部分 UV 段的重合证据已修正：平面和直线求交与投影一致，限制曲线构造要求当前段域。整域中位于 UV 段外的重合不再直接转成当前段的 NonUnique；公开回归正反方向均先失败后通过，并保留段内部分区间真实重合的正向对照。该修复不改变无证明时的 Unknown 完整性，详见 M25 曲面曲线接口说明。

已采用 rational NURBS，明确权重、参数域、周期标志及导数阶数，并实现共享解析 basis/导数。H9 的曲线根隔离、多根返回、奇异及失败证据已按 [H8H9算法契约说明.md](H8H9算法契约说明.md) 实现；一般曲面仍受有限初值预算约束，完整性不能证明时返回 `Unknown`。曲面上曲线投影已接入严格段域的 NURBS 限制曲线候选，一次限制曲线按 span 复用解析线段投影，高阶限制曲线复用通用投影；原曲面回代校验和未知最优性证据保留。一般曲面及其余投影内核仍需继续收敛。

### D6 2D 多边形重建与布尔内核

M28 原始常量收敛本轮再清点：15 项默认别名无内部调用，Boolean／PathOps 的无用策略头已移除，四模块无平行固定 epsilon 字面量及旧模块常量引用；公开旧值、符号和数值路径保持。弧临界角表有两处使用。BrepConversion 的拟合上限已改为函数内私有常量，原 min(eps, 1e-12) 行为不变；八项旧模块常量现仅保留兼容声明定义、没有内部调用。其余具体入口按后续条目验收。

M28 Offset 的固定重建重试已核对为默认兼容策略：显式单／集合入口均关闭 allowLegacyRetry，OffsetToMultiPolygon 的显式委托也保持关闭。两个既有公开定向回归通过，调用表见 [M28容差迁移说明](M28容差迁移说明.md)。该常量分支不再列为已疑似扩大调用者容差的问题；其他偏移、采样及容差回退仍须分别举证，不据此关闭一般数值能力验收。

基础重建、诊断和分支回退已收敛到 `SCPathOps` 共享入口；`CutPolygon` 两个公开入口共用布尔裁剪与失败模型，详见 [H8H9算法契约说明.md](H8H9算法契约说明.md)。一般 Boolean 的失败模型、epsilon 分层和其他平行实现仍需继续收敛。
