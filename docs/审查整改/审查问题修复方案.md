## 修复方案

### D1 模块边界与公开头迁移

定义 Foundation/Types、2D、3D、Brep、Algorithms 的单向依赖图，明确结果类型归属、唯一 umbrella、旧 include 的兼容期和弃用策略。先提交依赖图与迁移表，再按“类型→接口→算法→Brep”迁移；旧头仅保留转发并标记弃用，增加单头编译检查。

### D2 数值与 API 契约统一

统一 2D/3D 的类型泛化、归一化、越界、空结果和容差语义。求逆接口已统一使用 `std::optional`，矩阵与变换的失败条件和容差规则见 [H3求逆接口变更说明.md](H3求逆接口变更说明.md)；本次按要求直接替换接口，不保留旧返回类型兼容层。

### D3 空间索引产品语义

明确采用持久索引或查询时构建容器，定义更新一致性、复杂度、线程安全和 KNN `eps` 语义。使用暴力扫描作为 oracle，覆盖 Add/Remove/Update、KNN、距离和边界行为；若不实现持久树，应改名并在 API 中明确语义。

### D4 B-rep 数据模型与布尔能力

确定 `SCBrep`/`Polyhedron` 的主表示、转换边界、拓扑所有权和稳定访问方式，建立 Boolean 能力矩阵及退化规则。当前一般 CSG、重合支撑面、低维接触、非凸或多 shell body、曲线边界以及一般并集/差集仍需设计后实现，不能用局部启发式扩展。

### D5 NURBS 与求交/投影数值内核

决定补齐 rational NURBS 还是改名为 `SCBSpline*`，明确参数域、周期性、导数阶数和求解器收敛契约。先实现共享解析 basis/导数，再以统一投影内核支撑点-曲线、点-曲面、线-曲线和线-曲面求交。

### D6 2D 多边形重建与布尔内核

确定 `SearchPoly` 是否作为唯一 arrangement/ring-rebuild 内核，统一 `CutPolygon` 与 Boolean 的失败模型、epsilon 分层和诊断信息；以差分回归锁定现有行为后删除平行实现。

### 构建、重复与文档收尾

继续收敛三角化、采样、环遍历、epsilon 和公共 helper 的重复实现；统一版本与安装目录来源，明确 GTest 离线策略及 shared/static 安装验证；同步 README、命名计划、CI 声明、编码规范和测试覆盖文档。
