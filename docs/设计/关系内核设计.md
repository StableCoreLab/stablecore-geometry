# 关系内核设计

## 1. 适用范围

本文定义二维段、盒和多边形正面积关系查询的内部数值契约。它服务于 `SegmentBoxRelation2d` 与正面积查询实现，不新增公共 API，也不改变既有通用 arrangement 的调用契约。

目标是区分“可靠无交”与“当前数值条件下无法可靠判定”。不能将后者折叠为无交、`false`、`Disjoint` 或空结果。

## 2. 统一状态

内部段对求交统一使用以下状态：

```cpp
enum class CheckedPairStatus2d
{
    Success,
    NoIntersection,
    InvalidInput,
    NumericalIndeterminate
};
```

- `Success`：交点或重叠区间有限，并已经由方程和参数域验证。
- `NoIntersection`：当前段型的完整解析分支可靠证明不存在公共点。
- `InvalidInput`：输入段、坐标或前置条件无效。
- `NumericalIndeterminate`：有限输入下出现溢出、非有限中间值、稳定性带内判别式或不可可靠比较。

最近点距离、公共 `Intersect` 的空结果、包围盒分离、空事件和默认构造值都不能单独证明 `NoIntersection`。

## 3. 不变量

1. 公共入口构造的扩张盒只构造一次；局部缩放不能改变点、段参数、盒边界或最终关系。
2. 段参数使用闭区间 `[0, 1]`。参数落在稳定性带时必须重新验证；禁止通过 `clamp` 把段外根转换为端点交点。
3. 正长度重叠必须输出两个不同端点。数值阈值只能判断可靠性和事件去重，不能把重叠改写为点。
4. checked arrangement 不得在后续步骤调用未检查的分割、求值、参数去重或切线排序逻辑。
5. 任何跨层失败必须保留为明确失败枚举，不能转化为成功结果。

## 4. 局部归一化和稳定性带

局部归一化仅用于中间计算，不是第二套几何容差。

对每个参与求交的段对，先以端点、圆心和半径绝对值的最大有限量构造 `coordinateScale`；在预缩放空间平移后，再以弦长、圆心差和预缩放半径的最大有限正量构造 `pairScale`。坐标和半径必须始终使用同一比例缩放。比例为零、不可表示或变换后非有限时，返回 `NumericalIndeterminate`。

行列式、二次判别式、同圆判断和角区间端点均按归一化坐标计算误差界：

```text
errorBound = C × u × sumAbsTerms
```

其中 `u` 是 `double` 的单位舍入，`C` 是对应辅助函数具名的有限运算上界。

- `value > errorBound`：可靠正；
- `value < -errorBound`：可靠负；
- `abs(value) <= errorBound`：仅在代数恒等式可再次确认时进入零或重合分支，否则返回 `NumericalIndeterminate`。

稳定性带只决定“成功”或“不确定”，不能创造交点、删除交点、扩张盒或放宽参数范围。

## 5. 段对求交

| 段对 | 可靠无交条件 |
|---|---|
| Line-Line | 平行非共线、共线投影严格分离，或非平行参数可靠落在范围外 |
| Line-Arc | 二次判别式可靠为负，或所有有限根均可靠在直线段或圆弧范围外 |
| Arc-Arc | 同圆角区间严格分离；异圆的圆心距离与半径关系可靠证明分离，或每个有限交点都在至少一条圆弧范围外 |

每个成功交点必须验证：点有限、两条段的参数均位于闭区间、从参数重新求值得到的两侧点与交点一致。

Arc-Arc 先区分同圆与异圆。同圆时以带方向的半开角区间处理，完整圆单独标记；空交集为无交，单角为点，正角长度为重叠。异圆时依次可靠判断外离、内含不接触、相切或两点相交，并对每个候选点验证圆方程、角区间和参数。

## 6. 段-盒关系

段-盒关系只使用一个局部坐标框架和完整 checked 求交器：Line 与盒边使用行列式和共线投影区间；Arc 与盒边使用圆线二次方程和圆弧角区间。

任一局部求解、事件排序或代表点求值不确定时，段-盒公共层返回其既定失败状态；不得用“未发现事件”继续推断分类。

## 7. 正面积专用 Arrangement

正面积查询建立专用 checked arrangement，不能复用只返回空/非空结果的通用 arrangement。

它必须独立完成：

- checked 段对事件收集；
- 参数插入、排序和去重；
- Line/Arc 的局部解析分段与有效性验证；
- 切线方向计算和半边排序；
- 面代表点、面积和两个填充集合的严格定位。

参数顺序、同一事件和切线角只要无法可靠决定，就返回 `NumericalIndeterminate`。所有面完成面积和填充定位后，才可返回正面积关系结果。

## 8. 公共失败映射

| 内部来源 | 公开层要求 |
|---|---|
| 段无效 | 输入无效失败 |
| 非有限计算结果 | 非有限结果失败 |
| 求交、排序、分段不确定 | 数值不确定或求交失败 |
| 面代表点或填充定位失败 | 面分类失败 |
| 可靠无交 | 继续后续分类，不产生交点事件 |

正面积查询失败时必须满足 `success == false`、`hasPositiveAreaIntersection == false` 且 `failure != None`。

## 9. 验证要求

测试至少覆盖极大/极小有限坐标、近切、近乎平行、端点稳定性带、同圆不同分段、完整圆、反向圆弧、正长度重叠、孔洞、交换对称性和失败传播。对于极端尺度输入，未能可靠判定应被验证为失败，而不是被断言为无交。
