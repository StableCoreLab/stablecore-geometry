# 平面与多边形拓扑设计

## 1. 范围

本文定义平面构造、二维曲线环规范化、包含关系、洞环追加和确定性三角化的公共语义。模型只使用既有 `SCPolyline2d`、`SCPolygon2d` 和 `ISCSegment2d`，不引入业务专用区域或环类型。

## 2. 平面构造和高程

`Core/PlaneOps.h` 提供三点构造、XY 梯度构造和 XY 高程求值。`SCPlaneTolerance` 包含点容差与相对角度容差，两者必须是有限正数。

三点构造先以点容差拒绝重合点，再按下式判断共线：

```text
|cross(u, v)| <= relativeAngularTolerance × |u| × |v|
```

梯度构造使用归一化 XY 方向 `d` 和法向量：

```text
normal = (-risePerRun × d.x, -risePerRun × d.y, 1)
```

高程求值拒绝垂直或近垂直平面，不返回钳制值、无穷值或不声明的近似值。所有结果遵循：成功时 `failure == None` 且值有效；失败时不暴露部分平面或高程。

## 3. 多边形公共操作

```cpp
NormalizePolygon(polygon, validationTolerance);
TessellateAndTriangulatePolygon(polygon, validationTolerance, deterministicTolerance);
ClassifyContainment(container, candidate, validationTolerance);
AppendHole(polygon, hole, validationTolerance);
```

所有容差都必须有限且为正。失败结果的 polygon、顶点和三角形保持空值；包含关系无法判断时必须为 `Unknown`，不得伪装为 `Disjoint`。

## 4. 规范化

规范化按以下顺序执行：

1. 验证环闭合、段连续、段有效和坐标有限；
2. 对非相邻段、非共享端点的相邻段、外环与洞、洞与洞进行精确曲线求交；
3. 按源参数排序事件，区间重叠独立处理；
4. 仅合并坐标和源参数均在各自阈值内的同一事件；接近但参数不同的事件返回拓扑歧义；
5. 使用曲线积分计算有符号面积，拒绝退化环；外环规范为逆时针，洞环规范为顺时针；
6. 通过精确反向改变段方向，不把 Arc 改写为折线；
7. 以批量分割后的原子边构建 arrangement，验证洞严格位于外环填充区且洞间不接触、不相交、不互含。

失败时返回第一个确定的 `loopIndex` 和 `segmentIndex`。输入环和洞的相对顺序不应被无理由重新排序。

## 5. 包含关系和洞环

`ClassifyContainment` 使用同一份规范化曲线 arrangement 对两个填充集合分类：

- 穿越或边界重叠：`Intersecting`；
- 仅边界接触：`Touching`；
- candidate 为 container 填充区真子集：`StrictInside`；
- candidate 完全位于 container 的同一个洞内：`InsideHole`；
- 其余无公共填充区：`Disjoint`。

`AppendHole` 先将候选环规范为无洞 polygon，只有 `StrictInside` 时追加，再整体规范化。候选位于洞内、接触、相交、重叠或无效时均失败。

## 6. 确定性采样和三角化

三角化必须先规范化，再从同一份精确 polygon 产生边界顶点和三角形。每条段的参数序列包含 `t = 0` 和 `t = 1`，并严格递增；环拼接时跳过各段末端点以避免重复连接点。

Line 的参数序列固定为 `{0, 1}`。Arc 的分段数由半径、扫角和 `deterministicTolerance` 确定；分段数不可表示、超过实现上限或无法得到有效步长时返回 `TessellationFailure`。

每个输出顶点保留：稳定顶点编号、环索引、源段索引、源参数和坐标。稳定顶点编号是扁平输出数组的零基序号。算法、舍入或编号规则出现不兼容变化时，提高结果中的 `algorithmVersion`。

三角化实现必须验证索引范围和互异性、正面积、三角形中心位于填充区，以及三角形总面积与采样区域面积一致到规定误差。
