# 模块依赖与公开头迁移

## 当前边界

`Types` 与 `Support` 共同构成基础层：值类型使用共享容差，少量辅助函数又使用值类型。公开头的目标依赖方向为：

```text
Types / Support → Geometry2d → Geometry3d → Brep → Core → Geometry.h
```

箭头表示右侧可以依赖左侧；`Geometry3d` 仅在曲面上的二维参数曲线等场景依赖 `Geometry2d`。`Core/Section.h` 需要 B-rep 实体，因此 `Core` 位于 B-rep 之上。`Brep/Topology.h`、`Brep/BodyBoolean.h`、`Brep/Healing.h`、`Brep/MeshConversion.h` 与 `Brep/MeshRepair.h` 是旧包含路径的转发头；其实现均已从 `Source/Brep` 归位至 `Source/Core`。Brep 旧头只承担包含兼容，不代表新的 Brep 功能可以反向依赖 Core。新旧公开头均由独立翻译单元编译检查。三维求交、投影、关系、结果证据及平面曲线根实现，以及二维多边形、路径和二三维索引实现均已归位至 `Source/Core`。依赖 Core 声明且只供 Core 使用的私有助手现归入 `Source/Core/Detail`；供较低层复用的数值和容器助手保留在 `Source/Detail`。直接包含扫描确认 `Source/Geometry2d`、`Source/Geometry3d`、`Source/Brep` 和 `Source/Detail` 均不直接包含 Core 公开头。

当前公开头的直接包含扫描显示，`Brep/BodyBoolean.h` 与 `Brep/Healing.h` 所需的三维容差类型可直接来自 `Types/Geometry3d/SCGeometryTypes3d.h`。新增 Brep 公开头应直接包含实际使用的低层类型，不以 `Core/GeometryTypes.h` 获取传递声明。

## 公开头迁移表

| 旧路径 | 新代码入口 | 兼容策略 |
|---|---|---|
| `Core/GeometryApi.h` | `Geometry.h` 或具体能力头 | 旧头转发到唯一聚合头 |
| `Core/Algorithms.h` | `Geometry.h` 或具体 `Core` 算法头 | 旧头转发到唯一聚合头 |
| `Core/GeometryTypes.h` | `Core/GeometryTypesPrimitives.h`、`Core/ProjectionResults.h`、`Core/Geometry2dResults.h`、`Core/IntersectionResults3d.h` | 旧头保留结果类型聚合 |
| `Brep/Topology.h` | `Core/PolygonRelation2d.h` | 旧头仅转发纯二维拓扑接口 |
| `Brep/BodyBoolean.h` | `Core/BodyBoolean.h` | 旧头仅转发依赖 `Core/Measure.h` 的布尔能力接口 |
| `Brep/Healing.h` | `Core/Healing.h` | 旧头仅转发依赖 Core 关系、形状与校验能力的修复接口 |
| `Brep/MeshConversion.h` | `Core/MeshConversion.h` | 旧头仅转发依赖 Core 投影、形状与三角化能力的转换接口 |
| `Brep/MeshRepair.h` | `Core/MeshRepair.h` | 旧头仅转发依赖 Core 三角化能力的网格修复接口 |

上述旧路径在当前 1.x 版本保留。删除任何旧路径均需单独审查公开接口和安装后消费者，不能随内部文件搬迁顺带删除。旧路径中的转发注释和本表共同给出迁移提示。

`SCNurbsCurve3d` 与 `SCNurbsSurface` 的校验、求值和数值基函数由库实现文件提供；`NurbsBasis.h` 已归入 `Source/Detail`，不属于安装接口。公开头中保留构造、简单访问器和 `Detail::EvaluateValidatedNurbs*` 声明，后者供库内部求解器调用。

二维环面积与一阶矩助手 `RingIntegral2d.h` 也位于 `Source/Detail`，供 Geometry2d、Detail 和 Core 实现共用；该头不安装。`Source/Core/PolygonRelation2d.cpp` 直接包含自己的公开声明头，`Brep/Topology.h` 只承担旧路径兼容。

`BodyBoolean`、`Healing`、`MeshConversion` 与 `MeshRepair` 实现均使用 Core 算法，因此主公开头与实现归入 Core；Brep 旧头保留包含兼容。实现仍可使用 B-rep 实体与内部环几何助手，外部导出符号和旧调用签名保持不变。

## 验证入口

- `SCGeometryPublicHeadersCompile` 检查公开头组合编译。
- `SCGeometryStandalone*Compile` 分别检查唯一聚合头、兼容转发头、三维求交结果头及 NURBS 头的独立包含。
- `SCGeometry.PackageConsumer` 从安装包包含 `Geometry.h`，调用 NURBS 曲线和曲面，检查动态库导入与符号链接。
