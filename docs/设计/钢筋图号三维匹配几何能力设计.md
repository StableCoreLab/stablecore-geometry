## 3. 公共类型与失败契约

### 3.1 显式容差

```cpp
struct GEOMETRY_API SCPathGeometryTolerance
{
    double distanceTolerance{0.0};
    double angleToleranceRad{0.0};
    double relativeTolerance{0.0};

    [[nodiscard]] bool IsValid() const;
};
```

| 字段 | 单位及有效范围 | 用途 |
| --- | --- | --- |
| `distanceTolerance` | 与输入坐标相同，有限且大于 0 | 重合、离线、离面、连接点一致性 |
| `angleToleranceRad` | 弧度，有限且在 `(0, π/2)` | 方向、法向、平行判定 |
| `relativeTolerance` | 无量纲，有限且在 `(0, 1)` | 最优平面唯一性、单位基检查；不得用来按整体长宽比拒绝细长平面 |

所有新增入口必须显式传入该容差，不提供省略容差的重载，不依赖全局可变容差，不更改现有容差类型。默认构造的容差无效，调用者必须明确设置三项值。库内不得写入钢筋匹配业务阈值。

单位正交值另有不可放宽的数值表示门禁：库内固定 `kPathRepresentationTolerance = 64 × std::numeric_limits<double>::epsilon()`，不是业务容差或可变配置。单位长度误差上限为 `min(relativeTolerance, kPathRepresentationTolerance)`，单位轴点积绝对值上限为 `min(sin(angleToleranceRad), kPathRepresentationTolerance)`。调用者放宽几何容差不能把斜基或椭圆参数当成单位正交基或圆。所有生成与消费服务共用同一内部校验；调用者给出的容差小于当前运算可达到精度时结构化失败，不假装满足更严的误差要求。

各结果使用相同字段模式，完整声明见第 3.3 节，不引入新的公共模板结果框架：

```cpp
bool success{false};
SCPathGeometryFailure failure{SCPathGeometryFailure::None};
std::optional<std::size_t> inputIndex{};
std::optional<std::size_t> relatedIndex{};
```

成功时 `success == true` 且 `failure == None`。失败时 `success == false` 且原因非 `None`，几何载荷不可用，不返回部分成功，不以默认零长度或虚构坐标表达成功。输入校验的固定顺序为容差、按原始下标遍历的非有限输入、几何有效性、数值求解和输出有效性。

点列接口的 `inputIndex` 表示输入点下标，段列及偏移接口表示输入段下标；简化结果的 `inputKind` 区分两种重载。圆弧构造只对起点、终点、圆心非有限或端点不一致使用点下标 0、1、2；法向、半径、扫角及架/平面本身的错误下标留空。`relatedIndex` 定位连接的另一段或自交段。没有唯一可定位输入时两项留空，不能用 0 冒充未定位。

显式容差无效返回 `InvalidTolerance`；非法枚举闭合值返回 `InvalidClosure`；偏移 miterLimit 非法返回 `InvalidOptions`。失败时所有载荷重置为下列默认值，仅 failure、定位字段及简化 inputKind 保留。输入有限性检查早于任何 `IsValid()`、长度求值或采样，避免把非有限输入错误归为退化。

几何输入错误不用异常表达；内存分配失败沿用标准容器语义，不要求转换为几何失败。所有输入保持不变，结果拥有自身数据；不返回指向调用方 span 的悬挂引用。

## 4. 平面拟合、坐标架与投影

### 4.1 多点最佳拟合平面

采用等权正交最小二乘。输入至少三个点，所有点包括重复点均参与等权统计，不擅自去重后改变权重。

1. 先检查相对首点的全部距离：均不大于距离容差返回 `CoincidentPoints`。按下标三元组字典序寻找第一个有效非共线三点，找不到返回 `RankDeficient`。这一步是几何退化判定，不使用整体长宽比。
2. 按输入顺序，以首点平移、最大绝对差值分量缩放、补偿求和得到归一化质心和 N×3 中心化坐标矩阵 A。所有重复点仍保留一行。差值、尺度和还原结果检查有限性，不可表示返回 `NonFiniteResult`。
3. 对 A 做库内单边 Jacobi SVD，不先构造 AᵀA，避免平方条件数淹没细长输入。列对旋转顺序固定为 `(0,1)`、`(0,2)`、`(1,2)`，同步累计 3×3 右旋转矩阵 V，最多 32 个完整扫描。点积按输入顺序补偿累加；列范数用缩放范数求值。对非零列检查 `abs(Dot(col_i,col_j))/(norm_i*norm_j) <= 64 × binary64 machine epsilon`，用分别归一化列后的点积计算该比值，避免范数积溢出/下溢。零列不旋转。32 次后不满足收敛条件返回 `NumericalFailure`。
4. 列范数即奇异值，升序排列为 σ0、σ1、σ2，V 的列同步排序，相等时按旋转前列下标。σ1 为零或不大于 `64 × machine epsilon × σ2` 表示数值求解不足，返回 `NumericalFailure`，不能伪称几何共线。唯一性检查为 `σ1−σ0 > relativeTolerance × σ1`；不满足返回 `AmbiguousPlane`，不再用 σ2 为最小两轴的唯一性比较尺度。
5. σ0 对应 V 的单位列向量作为法向。使用步骤 1 的有序三点叉积定向，点积为负时翻转；单位有向法向与拟合法向的点积绝对值不大于 `sin(angleToleranceRad)` 时返回 `AmbiguousPlane`。
6. 平面原点取还原后的质心，按最终法向计算所有输入点有符号距离及最大绝对偏差。最优法向由 SVD 得到，不能以三点平面替代一般多点最小二乘。

三点 `(i,j,k)` 的几何见证固定为三边长度均大于距离容差，并检查三个循环顶点 `(i,j,k)`、`(j,k,i)`、`(k,i,j)`。取两条单位边叉积模最大的顶点作为数值求法向的顶点，平局按原下标；循环顺序保证叉积的有序法向符号不变。该顶点的第三点到所选基边支持线的距离须大于距离容差。几何秩不使用 caller angleToleranceRad 筛除细长三角形；若几何非共线但最大单位叉积模不大于 kPathRepresentationTolerance，返回 NumericalFailure，不能伪称 RankDeficient。点数足够但所有三元组均在上述距离意义下退化才返回 RankDeficient。叉积和距离计算先缩放，不能把长度阈值直接用于无量纲法向。数值范数、旋转和还原使用 binary64，有限值运算中发现不能可靠表示的结果返回 NumericalFailure 或 NonFiniteResult，不得静默变成精确零长。

必须通过细长反例 `(0,0,0),(1e6,0,0),(1e6,0.1,0)`：在基础夹具容差下三点有效，FitPlane 成功且法向 +Z。该例即使协方差特征值比小于 `relativeTolerance` 也不能返回 RankDeficient。

拟合成功表示最优平面可可靠定义，不表示输入满足钢筋匹配的平面偏离阈值。Quantity 根据返回偏差执行业务判定；不能因超业务阈值丢失可用于失真示意的拟合结果。

### 4.2 平面坐标架

校验平面有限且法向非退化后归一化。平面法向允许任意有限非零缩放，归一化用稳健范数，不用长度单位的 distanceTolerance 判定法向是否为零。原点为第一个输入点在该平面上的正投影。按第 4.1 节同一有序三点规则定向 `n`；从首点到后续首个平面投影非重合点的方向归一化得到 `u`，`v = n × u`，再正交化并检查右手性。拟合单位法向、两类生成坐标架和构造圆弧均在返回成功前检查第 3.1 节同一表示门禁，生成值不能通过时返回 NumericalFailure。

法向无效返回 `InvalidPlane`；点数不足返回 `InsufficientPoints`；无法给出可靠有序法向返回 `RankDeficient` 或 `AmbiguousPlane`；无有效投影方向返回 `DegenerateDirection`。不能在失败时补世界轴法向。

### 4.3 共线坐标架

输入至少两点。首点为原点，从首点到后续首个距离大于容差的点得到单位 `u`；不存在该点返回 `CoincidentPoints`。检查每个点到该轴的垂距，超容差返回 `NonCollinear`，并定位第一个超差点。

三个世界轴中取与 `u` 绝对点积最小者，数值相等时按 X、Y、Z 顺序。将参考轴对 `u` 正交化、归一化得到 `v`，再令 `n = u × v`。两点直线不经过 FitPlane，不能被平面秩不足阻塞。

### 4.4 投影和逆变换

坐标架校验 origin 和三轴有限；三轴单位长度、两两正交满足第 3.1 节表示门禁，且 `Length(Cross(u,v)-n) <= 4*kPathRepresentationTolerance`，检查完整右手关系，不只比较同向。公开输入架不做隐式正交化，不能通过时返回 InvalidFrame；生成架先明确正交化再按同一门禁验收，失败返回 NumericalFailure。

- 投影为 `x = Dot(p-origin, u)`、`y = Dot(p-origin, v)`，同时返回 `Dot(p-origin, n)`。
- 逆变换为 `origin + x*u + y*v`，恢复的是平面正投影点，不恢复原始离面坐标。
- 空批量投影和逆变换允许成功返回空数组；坐标架仍须校验。
- 不修改输入、不钳制坐标；非有限中间值或结果返回 `NonFiniteResult`。

投影时用同一输入架将二维结果逆变换，并与 `p-n*Dot(p-origin,n)` 比较，误差须不超过 distanceTolerance；逆变换时把输出点用同一架投影回二维，误差同样不超过该长度容差，且输出的离面距离不超过该容差。有限结果因坐标尺度/舍入不能满足这些后置条件时返回 NumericalFailure。允许空数组成功不意味着跳过架校验。

同一输入固定遍历、排序和裁决规则。跨平台输出按已声明的距离、角度、相对容差比较，不承诺 binary64 逐位一致；拓扑顺序、下标映射和法向定向不能随机变化。

## 5. 真实长度与带映射简化

### 5.1 原始段编号及长度

开链 N 点产生 N−1 段，闭链 N 点产生 N 段，最后一段为末点到首点。显式重复末点仍先建立原始段编号，不先去重再编号。闭合标志以调用方参数为准，不从首尾距离推断。

使用稳健三维范数及补偿累计计算长度，检查差值与累计溢出。MeasurePolyline3d 至少需要两个点，允许路径中包含重复点和零长段；全部原始段精确为零时返回 `CoincidentPoints`，不把退化路径作为零值成功。只有端点三个坐标逐项相等才是精确零长，不能按长度下溢结果判断。构架、构弧和简化服务同样不能把全零路径当作有效几何。

段列重载的输入下标就是原始段号；直线长度由三维端点计算，圆弧长度由半径乘扫角绝对值计算。相邻端点须在距离容差内连续，闭链还检查末段到首段；超差返回 `DiscontinuousPath`。不得为了消除容差内间隙而改写输入圆弧定义或补连接段。

### 5.2 简化规则

- 保持输入方向，不跨闭链编号接缝归并。点列重载精确保留首输入点为锚点；段列重载以剔除前导精确零长段后的首个非零段实际起点为锚点，不声称保留被剔除零段的点坐标。架原点仍按第 4 节的原始有序点规则确定，不随简化锚点改写。
- 只归并方向一致、离线偏差满足距离容差、方向差满足角度容差的连续直线段，折返不归并。
- 每次扩大范围后检查范围内全部原始点，禁止逐点容差累计造成整体超差。
- 精确零长段可标为零长；短但非零段必须归属一个简化段，保留真实长度，不得按低于容差直接丢弃。
- 短段在满足完整范围校验时归入后续直线范围；不能向后归入时尝试前一直线范围，不能安全归并则保留。不得跨圆弧合并短段。
- 圆弧不按直线规则归并，不隐式采样降级；连续同圆弧本版本也保持独立段。
- 简化后纯直线开链至少两个有效点，纯直线闭链至少三个有效点，否则返回 `InsufficientRemainingPoints`。混合段链以至少一个有效段和声明闭合一致为准，允许单个整圆段。

确定性归并流程：先只剔除精确零长段；按源下标从小到大处理长度不大于距离容差的正长度段，尝试与下一个直线范围合并，再尝试上一个；随后从左到右贪心扩大连续直线范围，每次不满足条件即封口并开始下一范围。合并范围以首段起点到末段终点的弦为输出直线，弦须非零；全部原始正长度直线方向与该弦同向且夹角不超过角度容差；全部覆盖端点到弦支持线的距离不超过距离容差，沿弦参数须在 `[0,1]` 且按原顺序非递减。跨度内弧段禁止进入候选。失败的合并只意味着保留范围，不使整个合法输入失败。

短非零线段作为三维来源值允许保留，不调用带默认阈值的 `SCLineSegment3d::IsValid()` 决定其零长。三维简化成功仅保证本接口的来源值与容差连续性，不能据此宣称已生成有效 `SCPolyline2d`；二维消费必须经过第 7.3 节门禁。

剔除零段和全部归并完成后，必须重新校验输出相邻段连续性，闭链还检查末首；不能只依据输入每个间隙分别小于容差而认为删除后仍连续。输出连接超差返回 DiscontinuousPath，inputIndex 取前一输出段的 lastSourceSegmentIndex，relatedIndex 取后一输出段的 firstSourceSegmentIndex；不补连接段、不吸附、不返回部分映射。坐标架选点、简化去零和二维表示校验是独立门禁，不能互相跳过。

### 5.3 映射载荷

`sourceMappings` 按源段下标排列且条数等于原始段数。每个原始段恰有一项：`sourceSegmentIndex`、`simplifiedSegmentIndex`、`exactZeroLength`。精确零长段固定无目标且标记 true；正长度段必须有唯一目标且标记 false。

`coverages` 按目标段下标排列且条数等于目标段数。每项 first/last 为归属该目标的第一个/最后一个非零源段，下标两端均包含，范围中可有精确零长段。`sourceStartLength=sourceCumulativeLengths[first]`，`sourceEndLength=sourceCumulativeLengths[last+1]`，`coveredTrueLength` 独立补偿累加范围原始长度；不通过两个大累计值相减取得微小覆盖长度。不同 coverage 不包含同一非零段。前导/尾随零段只由 sourceMappings 表达，不强行扩展 coverage。

点列重载填充 `simplifiedPoints` 与对应直线 `simplifiedSegments`；闭链输出不重复末点，闭合由 closure 表达，开链输出包含最后端点。段列重载以 `simplifiedSegments` 为权威输出，`simplifiedPoints` 留空，避免把圆弧暗示为折线。inputKind 固定为对应重载的枚举值，所有长度数组使用第 3.3 节的确切字段名。

真实长度取覆盖原始段长度之和，不能用简化端点距离或二维投影长度代替。每个非零源段被计入一次，合并总真实长度与原始总长在累计舍入误差内一致。

### 5.4 下标映射示例

| 输入 | 原始段长度 | 输出及映射 |
| --- | --- | --- |
| 开链 `(0,0,0),(1,0,0),(1,0,0),(3,0,0)` | `[1,0,2]`，累计 `[0,1,1,3]` | 一条直线；源 0、2 → 目标 0；源 1 标为精确零长；范围 `[0,2]`，真实长度 3 |
| 开链 `(0,0,0),(δ,0,0),(2,0,0)`，`0<δ<distanceTolerance` | `[δ,2−δ]` | 一条直线；源 0、1 都 → 目标 0，真实长度 2，不能把源 0 标为零长 |
| 闭合正方形含显式重复末点 A、B、C、D、A | 四条边和最后的 A→A 零长段 | 保留四边与闭合标志，源 4 标为零长，源 0..3 各归属原方向的目标段 |
| 开链 `(0,0,0),(2,0,0),(1,0,0)` | `[2,1]` | 两条反向直线，不共线归并，真实总长 3 |

## 6. 三维圆弧构造与投影

### 6.1 构造

半径必须大于距离容差；单位法向长度与 1 的偏差不超过相对容差，校验后允许归一化，不接受任意长度的法向。

扫角范围为 `angleToleranceRad < abs(signedSweepRad) <= 2π`，支持正负扫角、跨零、近整圆和整圆，不支持多圈。端点重合不直接判退化，整圆依扫角定义有效。

检查起终点距圆平面的距离、径向长度误差均在距离容差内；由起点径向和法向按输入扫角旋转所得终点必须与输入终点一致，不反推另一条短弧或另一方向。起始径向经校验后正交化并归一化，按 `C+r*(e*cos(t*s)+Cross(n,e)*sin(t*s))` 计算标准圆采样，其中 e 为 startRadialUnit、n 为 unitNormal、s 为 signedSweepRad。返回三点 samples 和五点 fitSamples，两者的起点、半扫角点、终点逐项一致；标准端点与输入端点之差仍必须满足距离容差。所有采样值由 SCGeometry 计算，Quantity 不自行旋转或插值。

真弧长为 `radius × abs(signedSweepRad)`，任何中间值或采样结果非有限都失败。公共 arc 值在进入投影或简化服务时重新校验半径、扫角、法向、起始径向的单位性和正交性。

构造入口的 unitNormal 先按 caller relativeTolerance 检查接近单位，然后明确归一化；圆弧储存值则必须满足第 3.1 节不可放宽的表示门禁，法向和起始径向均近单位且点积近零。直接填入的公开 arc 不能在消费时偷偷归一化或更改定义：无效法向返回 InvalidNormal，无效起始径向或正交关系返回 DegenerateDirection，生成标准弧却无法通过同一门禁返回 NumericalFailure。这样 `radius*abs(sweep)` 始终对应已验证的圆定义，不用于非单位/斜径向产生的曲线。

### 6.2 平面投影

仅支持可用圆弧表达的兼容平面，不把倾斜圆投影成圆弧或折线。

1. 检查法向平行或反平行，方向差满足角度容差。
2. 检查整段弧的最大离面偏差，不只检查三个采样点。离面距离写成 `a + b*cos(t) + c*sin(t)`，在扫角区间检查端点及导数为零的所有候选角，最大绝对值不得超过距离容差。
3. 将圆心和起点投影到目标架，二维扫角按三维法向与架 `n` 的点积符号决定是否翻转。
4. 用原半径、投影起角和有符号二维扫角调用已有 `FromCenterRadiusStartSweep`，校验全部五个 fitSamples 的对应投影误差；结果 samples 返回输出二维弧自身的三个采样点。不能表示为现有二维有效弧时按第 7.3 节返回 `Unrepresentable2d`。
5. 返回真实三维弧长与二维构造弧长度，分别命名，不混淆。容差内近似投影必须满足上述采样与整弧离面校验；不满足返回 `IncompatiblePlanes`。

含弧拟合时 Quantity 先调用构造取得 fitSamples，沿事实加工顺序将每段弧的 1/4、1/2、3/4 点插在该段原始起终点之间，原始事实点各按点列原有位置出现一次。闭链不再额外重复首点；显式重复末点仍按事实输入保留。这只组装库返回的点，不在 Quantity 求解几何。半扫角点仍参与拟合，同时单个整圆增加两个非共线四分点，保证可进入 FitPlane 和 MakePlaneFrame。弧长始终来自构造结果，不用采样折线长度。

## 7. 严格带映射偏移

### 7.1 有符号语义和连接策略

正距离表示沿输入路径方向的左侧，负距离表示右侧。直线沿左法向平移；逆时针弧半径为 `r−d`，顺时针弧为 `r+d`，扫角方向保持不变。

仅支持 Line/Arc，不支持的段返回 `UnsupportedSegment`。半径塌缩、输出段过短或方向反转返回 `DegenerateOffset`。输入、距离、options 和容差必须先校验，不能依赖旧 Offset 的默认 epsilon 或失败哨兵。

已确认连接契约为**唯一交点连接**：相邻偏移支持线或支持圆相交，再按有向延续、有效扫角和斜接范围筛选交点，不增加额外连接段。

- 直线/直线、直线/圆、圆/圆均使用精确几何求交，不用显示采样。
- 交点应同时满足两段连接后的正长度、方向不反转、圆弧扫角不超过整圆；圆弧参数按距原连接端最近的连续展开角确定，多个有效展开位置无法区分则失败。
- 交点到原连接点的距离不得超过 `abs(d) × miterLimit + distanceTolerance`。
- 零个有效交点返回 `JoinNotFound`；多个有效交点返回 `AmbiguousJoin`；仅因斜接限值被剔除则返回 `MiterLimitExceeded`。
- 共线直线或同圆圆弧只在偏移后的原连接参数给出明确共享端点时连接，否则返回 `AmbiguousJoin`。
- 开链首尾保留各自独立偏移端点；闭链末首按同一规则连接。

禁止斜接钳制、插入桥接直线、自动圆角、反向重试、重建多边形或折线降级。现有 Offset 的此类行为保持原样，但严格入口不依赖这些分支。

### 7.2 最终校验与映射

输入表示和几何有效性检查完成后、求任何偏移连接前，对输入先做精确拓扑检查；完成全部连接后对输出再次执行同一检查。相邻段仅允许声明连接端点相接，非相邻接触、重叠或相交均返回 `SelfIntersection`；闭链第一段与最后一段按相邻段处理。两段闭链允许两段只在声明的两个首尾连接点接触，不允许除此之外的交点或重叠；单段闭链仅允许一个有效整圆，不将段与自身做成两段求交。按 `(i,j)` 下标对字典序报告第一个问题。输入自交不能因偏移后消失而成功。任何失败不返回部分路径。

零距离仍完整校验输入，成功返回独立副本和身份映射，不能提前绕过自交或非法段检查。

成功时每个输出段唯一对应一个输入段，原始顺序保持不变，不允许删除、分裂或增加段。映射每项包含：

| 字段 | 类型与语义 |
| --- | --- |
| `sourceSegmentIndex` | `size_t`，输入段下标 |
| `outputSegmentIndex` | `size_t`，输出段下标 |
| `sourceStartParameter`、`sourceEndParameter` | `double`，连接后端点在继承源参数化的偏移支持曲线上的参数 |
| `sourceLength2d` | `double`，输入二维段长度 |
| `outputLength2d` | `double`，输出二维段长度 |

参数定义在**继承原参数化的偏移支持曲线**上，不直接把偏移点代入原曲线。源直线 P0→P1、单位左法向 l 的偏移支持线为 `Q(t)=P0+d*l+t*(P1-P0)`；连接点 q 的源参数为 `Dot(q-(P0+d*l),u)/Length(P1-P0)`，其中 u 为源单位方向。源弧 `(C,r,a,s)` 的偏移支持圆为 `Q(t)=C+rOffset*(cos(a+t*s),sin(a+t*s))`；连接点在该圆上的连续展开角 θ 对应 `t=(θ-a)/s`。第 7.1 节确定同一展开分支，不能另按主值角重算。延长允许参数超出 `[0,1]`，不得钳制。每项 sourceLength2d 是整个输入段长度，outputLength2d 是裁剪或延长后的输出段长度，不把 sourceLength2d 解释为参数区间长度。

源三维真实长度由投影前及简化映射保留，通过 sourceSegmentIndex 串联追溯，不从偏移二维路径倒推。Quantity 的独立审计段长、尺寸基准及直径换算不进入该接口。

### 7.3 与现有二维对象的表示门禁

新增算法的数值判断使用显式容差，现有二维对象的 `IsValid()` 则是必须额外满足的表示约束，两者不互相替代。它们使用现有固定阈值的事实必须保留，不能为本需求改变旧接口、全局常量或调用者单位。

- 进入 OffsetWithMapping 时先检查原始段定义全部有限、caller 容差下的段有效性与连续性，再检查每段及输入 `SCPolyline2d::IsValid()`；若仅现有表示约束不满足，返回 `Unrepresentable2d` 并定位首个不能表示的段或连接。间隙满足 caller 容差但大于旧连接阈值也属于该失败，不吸附端点。
- 成功输出要求每个段及 `polyline.IsValid()` 均为 true，且仍满足 caller 容差。否则返回 `Unrepresentable2d`，不返回无效路径成功；zero-distance 分支同样执行此门禁。
- ProjectArcToFrame 构造的二维弧须 `IsValid()` 为 true；若扫角通过三维 caller 校验却小于旧二维弧阈值，返回 `Unrepresentable2d`，不能把它改成直线。
- Quantity 组装二维路径时以对应简化段顺序逐段投影，线段用现有端点构造、圆弧用 ProjectArcToFrame；使用段列构造 SCPolyline2d，不使用可能隐式去重首尾的点列构造器重建来源编号。尺寸转换不需要实际偏移时仍调用零距离 OffsetWithMapping 完成库内表示和拓扑验证；失败走业务主规范的回退，不在 Quantity 修补几何。
- 所有长度先用稳健公式求值并检查有限性，不能用旧 `Length()` 的零值失败哨兵作为新服务的成功值。

### 7.4 相邻段内角与有符号转折

EvaluateCornerGeometry 是通用二维几何服务，使用投影后的加工方向，输入分别是到达连接点的 incoming 和离开连接点的 outgoing。定位下标 0 表示 incoming，1 表示 outgoing；连接不连续时 inputIndex=0、relatedIndex=1。只支持 Line/Arc，先检查已知类型全部定义有限，再按显式容差检查非退化、各段现有 IsValid 和 `incoming.EndPoint()` 到 `outgoing.StartPoint()` 的距离；未知类型返回 UnsupportedSegment、零方向返回 DegenerateDirection、仅旧类型无法表示返回 Unrepresentable2d、连接超差返回 DiscontinuousPath。

直线切向为沿起终点的单位方向；圆弧切向为扫角符号乘径向单位向量逆时针旋转 90° 的方向，分别求 incoming 终点和 outgoing 起点切向。所有归一化、点积、叉积和 atan2 均由库内完成，不把公式交给 Quantity。

令单位切向为 a、b，原始转角 `φ=atan2(Cross(a,b),Dot(a,b))`，范围 `[-π,π]`。分类规则固定：

- `abs(φ) <= angleToleranceRad`：Straight，signedTurnRad=0、interiorAngleRad=π。
- `π-abs(φ) <= angleToleranceRad`：Reversal，signedTurnRad=π、interiorAngleRad=0；π 是折返的规范表示，不表示 Left。
- 其余 `φ>0`：Left；`φ<0`：Right；signedTurnRad=φ，interiorAngleRad=`π-abs(φ)`。

首尾两类明确在角度容差内规范化，误差不超过该容差，不混用浮点负零判定方向。输入方向有效的折返可表达为几何结果，由业务主规范决定是否允许；全零方向不能伪造 Straight。所有成功角度有限，长度单位不影响角度结果。闭链由调用方按段序对末首各调用一次；单段整圆不产生人为连接折点。图号固定角、钩角、可调范围和左右转与尺寸基准映射仍是 Quantity 的业务规则。

### 9.2 边界与公共交付夹具

在上述确定值夹具基础上补充：

- 拟合：最少点、重复权重、近共线、非平面但拟合成功、σ0/σ1 无唯一法向、尺度变化、平移、大坐标、差值或累计溢出。
- 坐标架：首点重复、首有效投影方向退化、世界轴平局、错误单位轴、非右手架、空投影、NaN 和 Infinity。
- 简化：容差临界两侧、逐点可归并但整体偏差超限、闭链接缝、短段不能安全归并、线弧混合和段列间隙超差。
- 圆弧：跨零角、近整圆、反法向、单位法向误差、非法起始径向、端点离面、倾斜圆整段离面极值、二维 IsValid 约束不满足。
- 偏移：负距离、线弧及弧弧唯一交点、无交点、多交点、斜接超限、支持曲线重合、多解角展开、半径塌缩、相邻重叠和非相邻自交。
- 折角：左右转、容差内直行和折返、线弧/弧弧切向、非连续连接、零方向、非有限与不支持段；匹配器只调用此接口求角，不自行解算。
- 公共交付：单独包含新增公开头、Geometry.h 可见性、DLL 导出、安装消费者、旧 Offset 和 Normalize 接口兼容。

每个边界夹具必须明确输入、容差和预期结果或失败枚举，不能仅以场景名称作为验收。映射验收同时检查唯一归属、顺序、累计长度和真实总长，不能只检查输出外形。

### 9.3 门禁状态

AI 仅做静态逻辑推断、公开声明一致性检查和设计对照，不运行测试。工程流程另行完成编译、动态测试、安装消费者及跨平台验证；未执行的检查不能记为通过。

只有公开 API 完整实现、失败语义和误差契约一致、独立验收完成后，才能声明本需求已交付并解除 Quantity 三维匹配阻塞。此之前 Quantity 不得在 Match、UI、Render 或 Command 中实现旁路几何算法；图号核心定义、存储和手工编辑仍可独立推进。
