# 测试覆盖说明

本文档只保留当前能力覆盖和当前能力差距，不保留历史过程记录。

## 测试分层

- `UnitTests/Capabilities`：已收敛、应稳定支持的能力测试
- `UnitTests/Gaps`：当前仍未闭合或明确未支持的差距测试

## 当前已覆盖的能力

### 二维

- Box、Point、Vector、Segment、Polyline、Polygon 的基础行为
- 距离、投影、反射、采样、偏移、关系判断、布尔运算
- `TangentPoints`、`SCLine2d`、`IntersectExtended` 的代表性场景
- `SearchPoly` 的确定性候选筛选、分支评分、诊断一致性、最小包含查询
- `SCBoxTree2d` 与 `SCSegmentSearch2d` 的 `QueryKNearest` 排序和距离场景
- `Shapes` / `PathOps` / `Topology` 相关能力

### 三维

- `Section` 的平面截取、组件重建、BRep/Polyhedron 结果稳定性
- `Healing` 的 trim 回填、open shell 修复、aggressive boundary-cap
- `BodyBoolean` 的闭体布尔、touching 子集、显式不支持契约
- `BrepConversion` 的修复、重建、对齐与拓扑回收
- 三维线段投影、`SCBoxTree3d` 与 `SCSegmentSearch3d` 的 `QueryKNearest`、`SnapPointToSegments3d` 的代表性场景
- `SCTriangle3d` 的小尺度退化高度判定及 `TriangleMesh::IsValid` 对有效小三角面的接受
- `SCPlaneSurface` 轴正交偏差与三维向量平行／垂直判断的弧度容差边界
- `SCDirection3d`、`SCRay3d` 的无效距离容差，以及 `SCIntervald` 的无效区间和包含边界
- 二维与三维直线、三维线段、平面、三角面及网格对负值或非有限容差的有效性检查
- 二维、三维点与向量对无效容差和非有限坐标的近似比较，以及空盒对无效容差的近似比较
- `ISCSegment2d` 基类入口的长度参数换算、线段与圆弧分派、截取语义及安装包导出符号
- `ParameterAtLength` 对小尺度线段与圆弧的显式容差、无效容差及短长度退化处理
- `SCPolyline2d` 显式容差下的短直线与圆弧混合路径按长度及归一化参数取点
- `SCCurveOnSurface` 在 NURBS 曲面上的 UV 段：单片与跨片同格三根、夹持和非夹持曲面两轴 knot 的有理曲面等价性、非夹持轴向段的夹持片路由、有理权重、反向参数、非单位 knot 域及重合状态；18 次有理限制曲线的同格三根及 32 次单根

## 当前能力差距

### `Section`

- 更一般的非流形轮廓拼接
- 超出显式 vertex-touch / edge-touch 子集的开放曲线与面积归并
- 非邻接 coplanar 片段的更一般合并
- 多层 boundary-attached 开放曲线裁决

### `Healing`

- 多 shell shared-boundary / shared-edge 裁决的更一般情形
- 复杂开放 shell 与网格/实体联动修复

### `SearchPoly`

- 更丰富的 fake-edge 解释
- 更完整的 ambiguous recovery

### `BodyBoolean`

- 更一般的 touching / overlap 子集
- shell-policy 相关更高阶裁决

### `SCCurveOnSurface`

- 限制曲线次数超过 32 或根隔离预算耗尽时的完整根隔离

## 当前判断

- 已闭合的能力应继续留在 `UnitTests/Capabilities`
- 仍然语义不稳定或覆盖不足的能力，继续留在 `UnitTests/Gaps`
- 如果某个 gap 已经具备明确、稳定、可复现的场景，应尽快转为 capability

## 交付标准

- 至少包含正常路径测试
- 至少包含边界测试
- 只要存在歧义，就必须有 gap 测试
- 结果与诊断必须一致
- `UnitTests/Gaps` 中标记为 `DISABLED_` 的测试记录尚未闭合的能力，通常在测试体中调用 `GTEST_SKIP()`；它们默认不执行。该目录也包含已启用的回归用例，不能把整个目录视为已跳过。

## 模块重构顺序

如果后续继续做模块级重构，建议按下面顺序推进：

1. `Section`
2. `BodyBoolean`
3. `SearchPoly`
4. `Healing`

这和当前能力收口方向一致：

- 先把平面切体和边线提取稳定下来
- 再把复杂体相交和并差结果稳定下来
- 再把二维闭合搜索和歧义恢复补齐
- 最后补修复链路，让上游输入更稳定
## 算法能力与剩余边界

`UnitTests/Capabilities/Core/TestAlgorithmCapabilities.cpp` 覆盖上述新增的切点、扩展相交、三维投影、最近邻和吸附代表性场景。`UnitTests/Gaps/Core/TestMissingAlgorithmsGaps.cpp` 与 `UnitTests/Gaps/Geometry3d/TestMissingAlgorithmsGaps.cpp` 保留以下边界：

- 切点在容差临界处的分类
- 扩展相交的退化重合情形，以及折线端点交点的去重稳定性
- 三维零长度或近零长度线段的投影边界
- 三维等距吸附的裁决规则；最近邻等距 ID 排序已有能力测试
